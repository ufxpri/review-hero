## 이 게임은

모든 존재가 **리뷰 카드(평점 판)** 를 달고 사는 세계. 별점이 곧 존재의 강도이고, 팩트에 부합하는 평가는 물리법칙처럼 작동한다. 당신은 리뷰 12,847건으로 이름을 얻은 전설적 리뷰어다. 협찬 받은 불량 보조배터리가 후기를 쓰던 중 폭발해 사망했고, 이 세계에 '오배송'되었다. **당신을 부르는 이름은 전생에서 쓰던 필명 하나뿐이다** — 그리고 이 세계 어디에도 없는 이름이라 아무도 당신을 추적하지 못한다.

당신에게는 리뷰 카드가 없다. 세계가 읽지 못하는 존재, **평가 불가(N/A)**. 신의 심판도 저주도 명중하지 않는 대신, 업적은 어디에도 기록되지 않는다. 남은 무기는 평생 갈고닦은 단 하나 — **리뷰를 쓰는 힘.**

```
오크 중량 전사가 [내려찍기]를 준비합니다.        ⚡ 인텐트 공개

 ▸ 제출: "무게가…" + "…불량입니다."
   → 초대형 둔기의 리뷰 항목 [무게] 적중 — 팩트! (×1.5)
   → 내려찍기 위력 반감 + 1턴 지연 = 캔슬. 신뢰도 +2

 ▸ 제출: "배터리가…" + "…쓰레기네요."
   → 이 대상엔 [연비] 항목이 없습니다 — 헛소리… (×0.5, 신뢰도 −2)
```

적의 인텐트를 읽고, **맞는 딴지**를 조합하는 것이 코어 퍼즐이다. 아무 말이나 던지는 억지 리뷰어는 신뢰를 잃고, 팩트로 찌르는 리뷰어만 크리티컬 리뷰를 쏜다.

## 핵심 시스템

| 시스템 | 요약 |
|---|---|
| 🃏 **접두+접미 조합** | "마감이…" + "…처참합니다." — 카드 두 장이 한 문장의 리뷰가 된다. 접두 16 + 접미 16 + 진상 특수 8 = 40장 |
| 🎯 **태그 판정** | 팩트(×1.5) / 일반 / 헛소리(×0.5). 무효 태그는 "평가 불가 항목"으로 상시 공개 — 숨은 정보가 아니라 읽기 게임 |
| 📈 **신뢰도 게이지** | 팩트를 쌓으면 논점별 크리티컬 리뷰 발동 — 팩트 폭격 / 진상 접수 / 힙스터 인증 / 바이럴 확산 |
| 💸 **리뷰 네고** | 상점 장비에 악평을 달아 할인받는다. 단, 그 악평은 런 내내 장비의 하자로 남는다. 하자를 화력으로 반전시키는 카드(「결함의 무기화」)까지가 한 세트 |
| 👿 **보스 리뷰** (비동기) | 보스에게 지면 리뷰를 남기고 떠난다. 전 세계 유저와 공유되는 디버프 슬롯 5칸을 두고 베스트 리뷰 경쟁 — 보스는 3턴마다 **사장님 답글**로 반박한다 |
| ✍️ **UGC 카드** | 금지어를 피해 직접 쓴 팩폭 리뷰가 AI 판정(등록 시 1회)을 거쳐 카드가 된다. 공감을 얻으면 닉네임이 각인된 정식 카드로 박제 |

## 문서 구조 — 이 저장소는 과정의 기록이다

기획 → 설계 → 제작 → 배포의 전 과정을 커밋 히스토리와 3층 문서로 기록한다.

```
review-hero/
├── design/            📕 정본 — 구현의 기준
│   ├── GDD-v1.0.md         시스템 설계 정본 (충돌 시 최우선)
│   ├── worldview-v1.0.md   세계관·용어 정본
│   ├── cards-v0.1.yaml     카드 데이터 (기계가 읽는 정본)
│   ├── enemies-v0.1.yaml   적 데이터
│   └── meeting/            11-에이전트 설계 회의록 (파트 6 + 상호작용 분석)
├── wiki/              📗 탐색용 위키 — Obsidian으로 루트 폴더를 볼트로 열기
│   ├── Home.md             진입점
│   ├── 시스템/ · 세계관/    한 페이지 = 한 개념, [[링크]]로 연결
│   ├── 용어사전.md
│   └── 결정기록/           📌 ADR 8건 — 기각한 대안과 사유까지 박제
└── CLAUDE.md          커밋 규칙: 모든 커밋에 [무엇을/왜/과정] 상세 기록
```

읽는 순서 추천: [`wiki/Home.md`](wiki/Home.md) → [`design/GDD-v1.0.md`](design/GDD-v1.0.md) → 궁금한 결정은 [`wiki/결정기록/`](wiki/결정기록/)

## 로드맵

| 단계 | 내용 | 기간 목표 |
|---|---|---|
| **Layer 1 — MVP** 🎯 | 1막 완결 싱글 런 (적 6종, 카드 40장, 전투 코어) | 3~4개월 |
| Layer 1.5 | 2·3막, 추가 적, 카드 해금 트리 | +2개월 |
| Layer 2 | 리뷰 네고 경제 (악평 할인, 5성 사기 판매, 진상도) | +1.5개월 |
| Layer 3 | 비동기 온라인 (보스 리뷰 슬롯, 유언, 사장님 답글) | +2개월 |
| Layer 4 | UGC — 유저 리뷰의 카드화 (AI 판정 파이프라인) | +1.5개월 |

전체 출시 목표 **12~15개월** · 운영비 상한 월 ~10만원 (1~2인 개발 전제)

## 기술 스택

- **클라이언트**: TypeScript 웹 — 전투/런 로직은 UI 무의존 상태머신 패키지 (시드 결정적, 서버 리플레이 검증에 재사용)
- **서버**: Firebase — Auth(구글 로그인) · Firestore · Cloud Functions · Scheduler
- **AI**: Claude Haiku — UGC 등록 시 1회 판정만 (전투 중 실시간 호출 없음)
- **이식**: 웹 → Tauri(Steam) 1순위, Godot 차선. Unity 배제
