# ADR-005: MVP = 1막 완결 싱글 런

- 상태: 확정 · 일자: 2026-07-30 · 출처: 실현성 검증 #1 채택

## 맥락

Layer 1(전투 싱글)의 원래 정의는 3막 18노드 풀 런이었다. 1~2인 개발로 3~4개월 내 달성 불가 판정.

## 결정

**MVP = "1막 완결 싱글 런" (6층, 적 E01~E05 + B01 의지 60, 카드 40장, 시작 덱 12장).** 게시판·RP/P·업보·네고는 전부 이후 마일스톤. 2·3막과 추가 적은 Layer 1.5(+2개월).

## 근거

- 코어 재미 검증(태그 판정 퍼즐이 재밌는가)에 3막이 필요 없다 — 1막 8~12분 런이면 충분
- 싱글 코어는 네트워크 없이 100% 동작해야 한다는 검수 기준과 정합

## 기각한 대안

- 시작 덱 10장안(05 제안): 12장안(01)이 R06과 정합해 채택
- 3막 축소판(막당 3층): 콘텐츠 절반을 만들고도 완결감 없음
