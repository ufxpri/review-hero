# ADR-004: 재화 2계통(RP·P) 통일, 계정 골드 폐기

- 상태: 확정 · 일자: 2026-07-30 · 출처: 상호작용 분석 R03 + 실현성 검증 #3

## 맥락

파트별 회의에서 계정 골드 / RP(명성) / 적립금(P) / 명성 스탯이 각자 정의되어 4계통이 난립했다.

## 결정

- 런 화폐 **골드** (런 종료 시 소멸) + 메타 재화 **명성(RP)** (랭크·노출) + **적립금(P)** (카드 해금)의 2+1 체계
- **계정 골드 폐기.** 비동기 배당은 P로 환산 지급 (10G→1P, 일 상한 30P)
- RP 지급 수치는 GDD §4.2 단일표가 소유 — 타 문서의 개별 수치는 전부 폐기

## 근거

- 메타 화폐가 런 경제로 유입되면 로그라이크의 런 독립성이 무너짐 (시작 자금 인플레)
- 1인 개발 규모에서 재화 4종의 밸런싱·UI·상점은 과적
