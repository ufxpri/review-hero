# ADR-010: 아트 방향 — 「만물마켓」 커머스 패러디 UI

- 상태: 확정 · 일자: 2026-07-31 · 출처: 아트 방향 3안 비교 후 사용자 선택

## 맥락

전투 엔진과 밸런스가 검증된 시점에서, 화면 설계를 시작하려면 비주얼 정체성이 먼저 필요했다. 세 방향을 전투 화면 목업으로 비교:

1. **커머스 패러디** — UI 전체가 쇼핑몰/리뷰 앱
2. 만물대장 장부 — 세피아 괘선 장부, 낙인 도장, 붓글씨
3. PC통신 터미널 — 청록 모노스페이스 BBS 감성

## 결정

**커머스 패러디 채택.** 게임 UI 전체가 「만물마켓」이라는 쇼핑몰 앱이며, 판타지 UI(양피지·검·마나바)를 쓰지 않는다. 적 = 상품 상세 페이지, 인텐트 = 발송 예정 알림, 패배 = 회원 탈퇴, 크리티컬 = 베스트 리뷰 등극.

## 근거

- **테마 = 메커닉 = UI의 3중 일치**: 리뷰가 무기인 게임에서 리뷰 작성 폼이 곧 전투 인터페이스 — 설명 없이 이해된다
- worldview §5 톤 원칙("세계는 진지하고 규칙이 웃기다")을 UI가 직접 구현: 화면은 진지한 커머스 앱, 거기 올라온 상품이 오크일 뿐
- 1~2인 개발 규모: 캐릭터 일러스트 없이 성립, 나중에 썸네일 교체만으로 비주얼 향상

## 기각한 대안

- **만물대장 장부**: 격조 있고 세계관 깊이가 살지만 일러스트·텍스처 리소스 부담이 크고, "리뷰 앱을 쓰는 감각"이라는 코어 재미와 거리가 있음. → 도감/해금 화면(S50)과 심사위원 관련 텍스트에 **명조체 레이어**로 부분 채택
- **PC통신 터미널**: 리소스가 가장 적지만 호불호가 갈리고 카드 게임의 촉감이 약해짐

## 부수 결정

- 다크 모드는 자동 반전이 아닌 별도 스텝 설계
- 실존 서비스의 식별 가능한 UI 모방 금지 (색·로고·레이아웃) — worldview §5.2 R17과 동일 기준
- 판타지 이펙트(폭발·번쩍임) 금지, 앱 관용 모션만
