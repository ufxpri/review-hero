# ADR-009: 밸런스 라운드 1 — 리포트 v1 제안 7건 전건 채택 + 침묵 규칙 6건 명문화

- 상태: 확정 · 일자: 2026-07-31 · 출처: balance-report-v1 §7 (사용자 결정: "다 적용")

## 맥락

시뮬레이터 실측(2,500판 × 20설정)에서 기준선 9항목 중 1개만 통과. 리포트가 GDD 변경 제안 7건과 GDD 침묵 규칙 6건을 결정 대기로 올렸고, 사용자가 전건 채택을 결정했다.

## 결정 (GDD v1.1)

| # | 변경 | 위치 |
|---|---|---|
| 1 | 팩트 판정 게이지 +2 → **+3** | GDD §3.3·§3.4, battle.ts |
| 2 | 정예 의지 상향 E02 30 / E03 24 / E04 22 / E05 28 | enemies-v1.0.yaml |
| 3 | B01 페이즈2 트리거 "의지 30" → **"의지 50% 이하" 비례** | §3.8, YAML, 엔진 |
| 4 | 보스 전투 길이 기준선 8~10 → **6~7턴** (a안 — 기준선 현실화) | §3.1 |
| 5 | 바이럴 크리 바닥 보장 (버프 0개 → +3 버프 부착, 상한 공유) | §3.5 |
| 6 | 불편러 크리 재설계 (기절 + **다음 행동 −50%** + 갈취) | §3.5 |
| 7 | 퇴고 액션 신설(교착 해소) + 보스 표준 검증 덱 정본화 | §3.2·§3.6 |

침묵 규칙 명문화: S07 봉인 경직 내성 / 은신 게이트와 카드 종별(크리=리뷰, 특수=비대상) / 재반박 대상 불문 / 성향 동률 fallback 순서 / 갈취만 전투당 1회 / 보스 표준 덱 — 전부 GDD 본문에 편입, 코드의 "가정" 주석 해소.

## 재검증 결과 (balance-report-v2)

- **해소**: 교착 패배 0건(퇴고), R11 역설 해소(48 하향 시 86.0% > 60 기준 83.2% — 하향=완화 정방향), 표준 크리 0.48→0.80회(목표 1 근접), 정예 길이 +0.3~0.7턴 개선
- **신규 이슈**: 플레이어 강화 4종(게이지 +3·불편러 −50%·바이럴 바닥·퇴고)이 중첩되며 **승률 인플레** — B01 표준 83.2%(기준 30~50%), 일반·정예 ~100%. 억지 처벌 여전히 미달. → **라운드 2 과제**로 GDD §11 등재

## 교훈

플레이어 측 버프 4종을 한 라운드에 동시 적용하면 개별 효과 검증이 불가능해진다. 라운드 2부터는 **레버 1~2개씩 적용→재시뮬**의 짧은 사이클로.
