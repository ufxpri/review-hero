# ADR-007: UGC LLM 판정은 등록 시 1회, 평가·분류만

- 상태: 확정 · 일자: 2026-07-30 · 출처: 사전 결정 + meeting/04 구체화

## 맥락

유저 작성 리뷰를 카드로 만들 때 "창의성을 누가 판정하는가": 규칙 기반(파훼 쉬움) / 유저 투표(콜드스타트) / LLM.

## 결정

- **LLM 판정, 단 등록 시점 1회만.** 전투 중 실시간 LLM 호출 전면 금지
- **LLM은 평가·분류만, 효과 창작 금지** — 효과는 고정 풀 12종 select-only, 창의성 점수는 배율 m(0.85~1.35)로만 반영
- 모델 claude-haiku-4-5 + 프롬프트 캐시 + structured outputs. 스팸 방어: 쿼터 5건/일, 해시 캐시, 첫 보스 처치 게이트 등 6종

## 근거

- 실시간 판정은 비용·지연·일관성 모두 실패 요인. 등록 1회면 계정당 월 비용이 $0.45로 캡됨
- LLM이 효과를 창작하면 밸런스가 LLM 출력에 종속 — select-only면 밸런스는 항상 고정 풀이 소유
