# 이세계 리뷰용사 — 설계 위키

리뷰가 공격·경제·성장 수단인 텍스트 중심 로그라이크 덱빌더. 싱글 코어 + 비동기 온라인, 1~2인 개발, 한국어 특화.

> **문서 지위**: 이 위키는 탐색용 파생 뷰다. 정본은 `design/GDD-v1.0.md`(시스템)와 `design/worldview-v1.0.md`(세계관·용어)이며, 충돌 시 정본 우선. 각 페이지 상단에 정본 출처를 표기한다.

## 시스템

**전투 (Layer 1)**
- [[전투흐름]] — 턴 시퀀스, 기절 규칙, 승패와 항복
- [[태그판정]] — 원산지/팩트/일반/헛소리 4단계 판정 (코어 룰)
- [[신뢰도게이지]] — 소스/싱크 전량표, 수급 시뮬레이션
- [[크리티컬리뷰]] — 성향 4종과 필살기
- [[카드체계]] — 대상 우선 단일 리뷰 60장, 원산지, ★ 읽기 규칙 ([[ADR-011-대상우선-단일리뷰-전환]])
- [[덱규칙]] — 시작 덱 12장, 획득·제거·순환
- [[플레이어장비]] — 슬롯 3, 공용 장비 스키마

**런·메타 (Layer 1~1.5)**
- [[런구조]] — 3막×6층, 노드, 온보딩 3판
- [[재화]] — 골드 / 명성(RP) / 적립금(P) 2+1계통

**경제 (Layer 2)**
- [[리뷰네고]] — 악평 할인, 악평 토큰, 진상도, 5성 판매

**비동기 (Layer 3)**
- [[보스리뷰]] — 슬롯 5 경쟁, 구매 인증, 배당, 사장님 답글
- [[유언과전단지]] — 유언, 전단지, 진열대, 주간 라운드

**UGC (Layer 4)**
- [[UGC파이프라인]] — LLM 1회 판정, 모더레이션, 박제

**인프라**
- [[기술스택]] — TS+상태머신 코어, Firebase, 서버 신뢰 모델

## 세계관

- [[만물대장]] — 아카식 레코드의 인게임 정본, 3원칙, 별점 등급
- [[계열의세계관]] — 4계열이 4대 원소를 대체한 근거
- [[주인공]] — '평가 불가', 필명 등록, 엔딩 3종
- [[환불원정대]] — 불려 온 자들. 전원 익명, 살아 있는 건 주인공뿐
- [[답글없는사장]] — 1막 보스. 「베스트 리뷰어」의 대리인 ([[ADR-013-체험단-베스트리뷰어-계층재편]])
- [[만물체험단]] — 리뷰를 **쓰는** 필멸자 조직. 올리는 것은 신의 일이었다
- [[베스트리뷰어]] — 최종 보스. 신이 사라지자 스스로 올리기 시작한 단원
- [[막구성]] — 1~3막 무대와 반전
- [[톤앤매너]] — "세계는 진지하고 규칙이 웃기다"
- [[용어사전]] — UI 표기 정본 (금지 표기 포함)
