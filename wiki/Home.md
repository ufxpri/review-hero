# 이세계 리뷰용사 — 설계 위키

리뷰가 공격·경제·성장 수단인 텍스트 중심 로그라이크 덱빌더. 싱글 코어 + 비동기 온라인, 1~2인 개발, 한국어 특화.

> **문서 지위**: 이 위키는 탐색용 파생 뷰다. 정본은 `design/GDD-v1.0.md`(시스템)와 `design/worldview-v1.0.md`(세계관·용어)이며, 충돌 시 정본 우선. 각 페이지 상단에 정본 출처를 표기한다.

## 상태

- GDD v1.6 / 세계관 v1.1. **클라이언트 = Godot 4 + C#(.NET 8), 데스크톱 전용 배포** ([[ADR-029-godot4-csharp-이관]]·[[ADR-030-데스크톱-전용-배포]]). 서버 = Firebase ([[ADR-008-기술스택-웹-파이어베이스]])
- 규칙 엔진(`engine/`)·YAML 로더(`data/`)·시뮬레이터(`sim/`)·xUnit(`engine.tests/`) C# 이관 완료. 구 TS 스택은 동결 병존
- **밸런스 라운드 1(v2) 반영** ([[ADR-026-밸런스-라운드1-v2]]) — 일반 배율 ×0.9, 적 의지 상향(B01 78), 방어 카드 하향. 잔여: 1막 런 자원 수지 (라운드 2)
- **카드 66장** — 방어 축·대상 균형 재배치 ([[ADR-023-방어축-호응회복-대상균형]]·[[ADR-027-찬양카드-보상경로]])
- **아트 방향**: 「만물마켓」 커머스 패러디 ([[ADR-010-아트방향-커머스패러디]]) — `design/art-direction-v1.md`에 화면 인벤토리 S01~S52
- 세계관: **수취인 불명·바깥 원칙·계정** 확정 ([[ADR-031-수취인불명-바깥원칙-계정]])
- MVP = **1막 완결 싱글 런**, 목표 3~4개월

## 시스템

**전투 (Layer 1)**
- [[전투흐름]] — 턴 시퀀스, 기절 규칙, 승패와 항복
- [[태그판정]] — 원산지/팩트/일반/헛소리 4단계 판정 (코어 룰)
- [[신뢰도게이지]] — 소스/싱크 전량표
- [[크리티컬리뷰]] — 논점 4종과 크리티컬
- [[카드체계]] — 대상 우선 단일 리뷰 66장, 원산지, ★ 읽기 규칙
- [[덱규칙]] — 시작 덱 12장, 획득·제거·순환
- [[플레이어장비]] — 슬롯 3, 방어 축, 공용 장비 스키마

**런·메타 (Layer 1~1.5)**
- [[런구조]] — 3막×6층, 노드, 온보딩 3판
- [[재화]] — 골드 / 명성(RP) / 적립금(P) 2+1계통

**경제 (Layer 2)**
- [[리뷰네고]] — 악평 할인, 악평 토큰, 진상도, 5성 판매

**비동기 (Layer 3)**
- [[보스리뷰]] — 슬롯 5 경쟁, 구매 인증, 배당, 사장님 답글
- [[유언과전단지]] — 유언, 전단지, 진열대, 주간 라운드

**UGC (Layer 4)**
- [[UGC파이프라인]] — LLM 1회 판정, 모더레이션, 박제

**인프라**
- [[기술스택]] — Godot 4 + C#, Firebase, 서버 신뢰 모델

## 세계관

- [[만물대장]] — 아카식 레코드의 인게임 정본, 6원칙, 연표, 별점 등급
- [[계열의세계관]] — 4계열이 4대 원소를 대체한 근거
- [[주인공]] — 수취인 불명, 이름·서명 등록, 엔딩 3종
- [[환불원정대]] — 불려 온 자들. 계정 하나에 대원이 갈아 끼워진다
- [[답글없는사장]] — 1막 보스. 「베스트 리뷰어」와 **같은 병의 다른 환자**
- [[만물체험단]] — 리뷰를 **쓰는** 필멸자 조직. 잘못 올라간 것을 지우던 것은 신이었다
- [[베스트리뷰어]] — 최종 보스. 지배의 근거는 권한이 아니라 실력이다
- [[막구성]] — 1~3막 무대와 반전
- [[톤앤매너]] — "세계는 진지하고 규칙이 웃기다"
- [[용어사전]] — UI 표기 정본 (금지 표기 포함)
