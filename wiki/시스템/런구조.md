# 런 구조와 온보딩

> 정본: GDD-v1.0.md §4.1, §4.3, §4.4

## 런 골격

- 3막 × 6층(일반 5 + 보스 1) = 18노드. 층당 노드 2~3 분기, 층당 1개 방문
- 보스 직전 층은 휴식(Layer 1.5 이후: 또는 게시판) 보장. 동일 유형 3연속 리롤
- **MVP는 1막만** ([[ADR-005-MVP-1막-축소]]). 노드: 전투 / 이벤트 / 상점 / 휴식 (게시판 슬롯은 이벤트로 대체)
- 플레이 타임: 풀 런 20~30분, MVP 1막 런 8~12분
- 휴식 노드: 의지 **30% 회복** or 카드 1장 무료 제거, 택1 (R09)

## 유언·업보 (조정)

- 유언 작성은 모든 사망 시 가능(Layer 3, 템플릿만). **좋아요 보상 집계는 "그 런에서 전투 승리 1회 이상"인 런의 유언만** — 자살 파밍 차단. "보스방 도달 게이트" 안은 기각(유언은 비동기 매력의 최전선)
- 업보 노드·카드 봉인·공양: **출시 후로 연기**

## 온보딩 — 1판 개념 11개 다이어트

| 판 | 도입 개념 | 보정 |
|---|---|---|
| 1판 | 조합 → 팩트/일반(무효 태그 없는 E01 변형) → 헛소리(원인 1줄) → 게이지 → 크리("필살 리뷰" 버튼) | 적 공격 ×0.75, 헛소리 −2→−1, 보스 약화판(의지 45, 야근 강요 미사용), 버프 무판정, 성향 UI 미노출, 항복 미도입 |
| 2판 | 항복(E02에서 자연 발견) → 버프 태그 판정 → 정예 → 성향 UI | 적 공격 ×0.9 |
| 3판~ | 정상 난이도. 이후 네고(L2) → 게시판·보스 리뷰·유언(L3) → UGC(L4) 순 도입 | 없음 |
