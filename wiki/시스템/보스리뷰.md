# 보스 리뷰 (Layer 3)

> 정본: GDD-v1.0.md §6 (meeting/03 승계 + 수정) · 서사 근거: [[답글없는사장]]

보스와 싸운 유저가 보스에 디버프 리뷰를 남기고, 전 유저가 공유하는 비동기 코어 시스템. v1 범위: 슬롯 경쟁·공감·사장님 답글·유언. 배당·전단지·주간 시드는 v1.1.

## 작성권 — 승리 시에도 발생 ([[ADR-003-보스리뷰-승리작성권]])

| 경로 | 조건 | 가중치 W | 명칭 |
|---|---|---|---|
| 패배 | 깎은 의지 30~59 / 60~89 / ≥90% | 1.0 / 1.5 / 2.0 (Tier 1/2/3) | 구매 인증 / 헤비 유저 / 최후의 증인 |
| 승리 | 처치 | 0.8 (Tier 1 상당) | 정복 후기(구매 확정) |

유저당 보스당 주간 1회. 재작성 시 공감 0 리셋 + 신선도 F=0 (최초 작성 1회만).

## 슬롯 경쟁

- 활성 슬롯 5개. `score = 공감V × W + F`, 신선도 F = max(0, 48−경과h)×0.5. 매시 배치 재계산, 전투는 시작 시점 스냅샷
- 디버프 위력 = `floor(풀 기본치 × Tier계수(0.8/1.0/1.25/1.5) × m(0.85~1.35))`, 절대 상한 = 기본치 ×2.0. 창의성 점수는 순위에 불개입
- **동일 계열 디버프는 슬롯 내 1개만 효과 적용** (담합 봉쇄 — 3번째부터 표기만). 감성(시작 게이지) 총합 캡 +3
- 공감 자격 = **첫 보스 처치 계정**. votes PK = (review_id, voter_id) 채널 무관 단일

## 사장님 답글 (보스 기믹)

- 3턴마다, **기절 중에도 발동**. 활성 디버프 중 Tier/위력 최상위를 **"이번 전투 한정 정지"** ("제거" 아님 — R18). 동률 시 공감↑→최근. [[크리티컬리뷰|힙스터 크리]]는 Tier3 상당으로 최우선 반박 대상
- 재반박: 같은 계열 접두로 팩트 판정 성공 시 디버프 부활 + 게이지 +1. 디버프당 1회
- 반박 대상 없으면 의지 +5만

## 배당 (v1.1)

처치당 10G 상당 → **P 환산 지급** (10G→1P, 일 상한 30P). 분배 `C_i = W_i×(1+V_i/10)`. **지분 0: killer 본인 + 동일 IP/디바이스 클러스터** (배당 링 차단). 작성자별 주간 상한 P 60. 복수 보너스 ×1.1. 일일 배치 정산.

## 서버 신뢰 모델 (Layer 3 착수 게이트)

클라 보고 불신 원칙: dmg_pct 클램프·Tier 서버 재계산, 작성권 서명 토큰(런 요약 제출→휴리스틱 검사→TTL 10분), 주간 시드는 결정적 리플레이 검증(상위 100+표본만). 상세는 [[기술스택]].
