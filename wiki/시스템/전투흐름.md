# 전투 흐름

> 정본: GDD-v1.0.md §3.1~3.2

## 기본 수치

- 플레이어: 의지 30, 필력([[용어사전|구 에너지]]) 3/턴, 손패 5장 유지(상한 8, 초과 시 드로우 중단)
- 적: 의지 + 장비 1~3개(내구도·태그) + 인텐트 공개 패턴
- 전투 길이 기준선: 일반 2~4턴 / 정예 5~6턴 / 보스 8~10턴. 플레이어 화력 턴당 8~12

## 턴 시퀀스

```
[전투 시작] 셔플 → 5장 드로우 → 게이지 = 0 + 외부 보정(캡 +3) − 감성 악평 페널티 p → 인텐트 공개
[플레이어 턴]
 1. 턴 시작: 내 도트 발동·만료, 예약 효과(X05)
 2. 드로우: 5장까지
 3. 필력: 3 + 보정
 4. 플레이: 리뷰 제출(접두+접미) / 특수 / X06 설치 / 퇴고(필력 1: 손패 1장 버리고 1장 드로우 — v1.1 교착 안전장치). 크리티컬은 별도 버튼(필력 0, 게이지 전량, 턴당 1회)
 5. 턴 종료 선언
[적 턴]
 6. 행동: 인텐트 순서 실행. X01 지연 시 스킵. 공격 선언 시 X06 대기 중이면 자동 발동
 7. 정리: 지속효과 tick, 기믹 카운터, 다음 인텐트 공개
```

## 기절 규칙

- 기절한 적은 그 턴 attack/buff/steal/stealth 행동 불가
- **gimmick 타입([[보스리뷰|사장님 답글]] 등)은 기절을 무시하고 발동**
- 기절에서 깨어난 적은 **1턴간 경직 내성**(기절·지연 면역) — S09 무한 락 봉쇄 (악용 검증 #3)

## 리액션 (X06 우리 애가 다쳤잖아요)

설치형: 대기 슬롯 1개, 적의 attack에만 자동 발동. 피해 −50% 후 남은 피해의 50% 반사. 전 히트 적용, 1회 소진. 적 턴 중 실시간 입력은 없다.

## 승패

- 적 의지 0 → 승리
- 적 장비 전부 파괴 → **항복** (승리 + 골드 +6G, 시간 단축 루트). 온보딩 2판에서 도입
- 내 의지 0 → 패배. 보스전 패배 시 [[보스리뷰|보스 리뷰 작성권]] 발생 가능
