# 리뷰 네고 (Layer 2)

> 정본: GDD-v1.0.md §5 (meeting/02 승계 + 수정) · 카드 기준: design/card-system-v2.md ([[ADR-011-대상우선-단일리뷰-전환]] 이후 단일 카드 체계)

상점에서 장비에 악평을 달아 할인받되, 그 페널티를 런 동안 짊어지는 시스템. 페널티는 런 종료 시 소멸. **Layer 2 기능** — MVP(Layer 1) 이후 도입.

## 할인 공식

```
할인율 = 카드 기본률 × 판정 배율 × NPC 배율
```

- 카드 기본률(cost 기준): 1코 12% / 2코 18% / 3코 25% — v1의 "0코 8%" 구간은 cost 0 금지([[카드체계]])로 소멸
- 판정 배율: 팩트 1.5 / 일반 1.0 (+진상도 1) / 헛소리 0 (+진상도 2). 무판정 진상 화법(X##)은 판정 자체가 없어 네고에 사용 불가
- 아이템당 악평 2건, 합산 50% 상한. 구매 포기해도 진상도는 유지
- 카드는 비소모(사본 부착)

## 악평 토큰 ([[ADR-002-악평페널티-스탯토큰]])

페널티는 덱 오염이 아닌 스탯 토큰. v1은 접두 계열/접미 비용이 각각 종류/강도를 정했으나, v2 단일 카드에선 **카드 `suit`가 종류를, 카드 `cost`가 강도 p(1~3)를 결정**한다:

| suit (계열) | 페널티 |
|---|---|
| 품질 | 전투 시작 의지 −p |
| 성능 | 패시브 p턴 비활성 |
| 배송 | 손패 p장 지연 |
| 감성 | **전투 시작 게이지 −p** (R02 — "크리 요구치 10+p"는 영구 봉인 버그로 폐기) |

상한: 장비당 2개, 전체 4개. [[플레이어장비|부착 슬롯 2칸]]을 버프와 공유 (R15).

## 결함의 무기화 — X09

비용 1, 무판정, **악평 페널티 1점당 의지 피해 3 (최대 5점)** — cards-v2.0.yaml `damage_per_penalty`. "자기 하자 고백은 언제나 팩트" — 네고 페널티를 화력으로 반전시키는 연결 카드. Layer 2에서 리뷰 네고와 함께 도입. (v1의 "Σp 상한 8·게이지 +1·전투당 1회·유니크" 사양은 v2 데이터로 대체됨)

## 진상도 (0~10, 런 지속)

- 3+: 프로 장사꾼 조우 확률 50% / 6+: 전 상점 +10% / 9+: 입장료 20G
- 보스 처치 −3. 사과문 세탁은 **이벤트 한정** (상시 세탁 금지)

## 판매와 5성 사기

기본가 40%. 5성 리뷰 2건까지: 팩트 +25%p(진상도 0) / 과장 +15%p(+1) / 허위 +30%p(+3, 프로 장사꾼에게 발각 리스크). NPC 3유형: 호구(×1.25) / 보통 / 프로 장사꾼(팩트만 인정, 실패 시 +10%). 고집쟁이 장인은 컷(보류).

## 데스 스파이럴 안전장치

시작 덱 12장 제거 불가([[덱규칙]] — v1 "생계형 리뷰" 하한의 계승), 골드 하한 0, 15G 미만 시 "체험단 모집" 무료 장비(런 1회), 휴식 무료, **테스트 게이트: 네고 0회 런 클리어율 차이 15%p 이내**.
