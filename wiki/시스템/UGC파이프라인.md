# UGC 파이프라인 (Layer 4)

> 정본: GDD-v1.0.md §7 · [[ADR-007-UGC-LLM-등록시-1회판정]]

유저가 직접 쓴 리뷰를 게임 카드로 등록하는 시스템. **v1 = "금지어 팩폭" 1구간만.** 유언 자유문·전단지 자유문은 v1.1, 사기극은 컷(보류).

## 흐름

```
작성(제약 프롬프트: 금지어 실시간 차단, 20~100자)
 → LLM 1회 판정 (창의성 점수 + 모더레이션 + 태그 자동 부여)
 → 내 런에서 사용 → 타 유저 노출(진열대) → 좋아요 상위 → 정식 박제
```

## LLM 판정 규칙 (등록 시 1회, 전투 중 호출 금지)

- 모델: claude-haiku-4-5, structured outputs, 시스템 프롬프트 ~4,500tok 캐시
- 창의성 = 유머 30 + 구체성 25 + 세계관 20 + 독창성 25 (축별 채점, 서버 합산)
- **효과는 창작 금지** — 고정 풀 12종 select-only + 배율 m = 0.85+0.005×score (0.85~1.35)
- 태그: 12종 사전 confidence 규칙 (≥0.7 상위 2개 / 0.4~0.7 1개 / 미만 무태그)
- 비용: 호출당 ~$0.003, 활성 유저 월 ~30회. 상한은 [[기술스택]] 운영비 참조

## 모더레이션

- 경미한 비속어 허용(게임 톤), 혐오·실존 인물 반려
- **브랜드 패러디: "믹도랄드"류 1글자 변형 전면 금지** — 식별 불가능한 일반화 치환("패스트푸드 왕국")만 제시 (R17, [[톤앤매너]]와 통일)
- 반려 시 사유 + 수정 예시 1개, 재제출 2회

## 스팸 방어 6종

서명 작성권 토큰 / 쿼터 min(랭크 쿼터, 5건/일) / 레이트리밋 / 정규화 해시 캐시(동일 텍스트 LLM 0회) / **첫 보스 처치 게이트** / 밴 에스컬레이션

- 표절 처리(E10): 해시 캐시 히트 시 최초 등록자만 원점수, 타 계정은 originality 0 + specificity 절반 ("표절 리뷰" 연출)

## 박제 (v1.1)

3중 게이트: score ≥90 + 30일 좋아요률 상위 5% + 주간 수동 큐레이션 3장 (원작자 확인 포함). 보상은 닉네임 각인 등 **순수 명예 — 골드 없음** (대필 유인 차단).
