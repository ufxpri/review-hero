# 카드 체계

> 정본: 규칙 = design/card-system-v2.md · 데이터 = design/cards-v2.0.yaml · 결정: [[ADR-011-대상우선-단일리뷰-전환]]
> ⚠ 밸런스 미검증 — 수치는 잠정값. 밸런스 라운드 1(v2) 재시뮬로 확정한다.

**카드 1장 = 완성된 리뷰 1건 (2~4줄).** 그리고 **카드보다 대상이 먼저다**: 리뷰 대상 16종(적 6 + 구성품 6 + 전생 상품 4)을 먼저 설계하고, 리뷰는 거기서 태어난다. 대상별 목록은 card-system-v2.md §3이 카드 데이터의 상위 정본.

## 구성 — 60장

| 종류 | 수 | 원산지 | 역할 |
|---|---|---|---|
| 전생 상품 리뷰 (Z01~Z12) | 12 | 없음 → **영구 미발동** | 시작 덱 전량 ([[덱규칙]]). 보조배터리·무선이어폰·배달음식·조립식 의자 — 이 세계에 없는 물건이라 원산지가 영원히 안 터진다. 시작 덱이 약한 이유의 세계관 해명 |
| 적 본체 리뷰 (G·O·L·D·N·B##) | 19 | 해당 적 | 적 6종(E01~E05, B01)에게서 태어난 리뷰 |
| 구성품 리뷰 (Q·W·M·C·A·K##) | 20 | 해당 적 + 구성품 | 구성품 6종(짝퉁 단검·초대형 둔기·과장된 지팡이·삐걱거리는 쌍단검·도금 갑옷·노예 계약서 낫) |
| 진상 화법 (X01~X09) | 9 | 없음 · **무판정** | 팩트 원칙 바깥의 언어 ([[만물대장]]). 판정 배율·원산지 모두 미적용. X09는 Layer 2([[리뷰네고]])에서 도입 |

카드 획득이 서사가 된다 — 카드 보상은 무작위가 아니라 **그 전투 대상들의 리뷰 풀에서** 나온다. 오크를 이겨야 오크 리뷰를 얻는다 ([[덱규칙]]).

## 스키마 (cards-v2.0.yaml)

```yaml
- id: W01
  name: "손목 나감"            # 짧고 기억에 남게
  origin: { enemy: E02, equipment: 초대형 둔기 }
  suit: 품질                   # 품질|성능|배송|감성 — 논점 산정 기준
  tag: 무게                    # 판정 태그 정확히 1개
  cost: 1                     # 필력 (최소 1)
  stars: 1                    # ★ 1~5 (아래 읽기 규칙)
  rarity: common              # basic|common|rare|legendary
  target: enemy               # enemy|enemy_equipment|my_equipment
  text: |                     # ★ 리뷰 본문 — UI 정본. 이 필드가 게임의 얼굴이다
    위력은 확실한데 손목이 나갑니다. …
  effect: { type: damage, value: 7 }
  ui: "의지 피해 7"            # 효과 요약 — 본문과 분리
```

- **`tag`는 정확히 1개, 배열 금지** (단일 초점 원칙) — 태그가 2개면 "무조건 좋은 카드"가 된다
- `text`(리뷰 본문)가 UI 정본, `ui`(효과 요약)는 본문을 오염시키지 않도록 분리

## 원산지

리뷰가 태어난 대상에게 다시 쓰면 최상위 판정 — ×1.5 + 고정 좋아요 +1, 게이지 +4, **무효 태그 무시** ([[태그판정]]).

- 적 본체 대상 제출 → `origin.enemy` 일치 시 발동 / 구성품 대상 제출 → `origin.equipment` 일치 시 발동
- 적 본체에서 태어난 리뷰(`equipment` 없음)는 그 적 본체에만 원산지
- 전생 카드(Z##)·진상 화법(X##)·**P(적립금)로 해금한 카드**는 `origin` 없음 → 영구 미발동. 원산지는 직접 이긴 대상에게서만 얻는다 — 주인공을 죽인 것이 안 겪고 쓴 협찬 리뷰였다는 사실이 규칙으로 남는다 (card-system-v2 §2)

## ★ 별점 = 카드 역할 (읽기 규칙)

별점은 장식이 아니라 효과를 예고하는 읽기 규칙이다. 카드를 열기 전에 별점만 보고 공격인지 버프인지 안다 — 60장이 되어도 손패 파싱이 가볍다.

| ★ | 성격 | 효과 계열 | 대상 |
|---|---|---|---|
| ★1~2 | 악평 | 의지 피해, 내구도 파괴, 기절, 디버프 | 적 / 적 구성품 |
| ★3 | 미지근 | 약한 피해 + 부가 이득 (드로우·게이지·회복) | 적 |
| ★4~5 | 찬양 | **버프** — 내 장비 강화, 데미지 증폭 | **내 장비** ([[플레이어장비]]) |

찬양 리뷰가 버프인 근거는 세계관에 있다 — 좋은 평가는 존재를 강화한다 ([[만물대장]] 평점 원칙). 내 장비에 별 다섯을 박으면 그 장비가 실제로 세진다.

## 필력 경제 — cost 0 금지

cost 0을 허용하면 손패를 전부 공짜로 던져 필력 자원이 무의미해진다. **최소 1** (예외: X03·X07만 0 — 둘 다 의지 피해 없음).

| 비용 | 역할 | 의지 피해 기준 |
|---:|---|---|
| 1 | 주력. 시작 덱 전량 | 3~7 |
| 2 | 효과 동반 또는 고화력 | 5~9 |
| 3 | 한 방 / 판을 뒤집는 카드 | 12~13 |

필력 3/턴 → 턴당 2~3장.

## 유니크 (덱 1장 제한)

**X04 무료 나눔, X08 별점 구걸** (cards-v2.0.yaml `unique: true`). X09는 유니크 미지정.

## 텍스트 규정

카드 문장은 완성된 리뷰 2~4줄, 실제 커머스 리뷰 문체(존댓말+별점 병기), 풍자:판타지 = 8:2 — [[톤앤매너]] 참조. 대상이 먼저 정해져 있으므로 리뷰는 반드시 그 대상의 구체적 결함을 짚는다 ("어느 상품에나 붙는 무난한 리뷰" 금지).
