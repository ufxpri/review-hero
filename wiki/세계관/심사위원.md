# 100인의 심사위원 (= 신)

> 정본: worldview-v1.0.md §1.2

[[만물대장]]에 **가중치 리뷰**(1건 = 필멸자 10,000건)를 쓸 수 있는 계정 100개. 신성의 본질은 권능이 아니라 리뷰 가중치다.

- **역할**: 각자 평가 카테고리 1개를 담당하는 MD(운영자). 전쟁·풍요의 신이 아니라 품질·물류·연산·감성의 관리자 — [[계열의세계관]] 참조
- **탄핵**: 심사위원은 죽지 않지만 탄핵당한다. 담당 카테고리 평균 ★2 이하 2분기 연속 → 자격 박탈, **명성 최상위 필멸자가 승격.** → 엔딩 B의 합법 루트이자 시즌 "심사위원 후보석" 칭호([[유언과전단지]])의 서사 근거
- **금기**: 심사위원끼리는 서로를 리뷰할 수 없다(**상호 평가 금지 조항**). 유일한 구멍이 '평가 불가'인 [[환불원정대장|주인공]] — 대장에 없는 존재는 조항의 적용 대상이 아니다. → 3막 반전의 핵심 ([[막구성]])

## 주요 심사위원

| 명칭 | 담당 | 비고 |
|---|---|---|
| 「검수관」 | 품질/마감 | |
| 「최적화의 현자」 | 성능/최적화 | |
| 「택배좌」 | 배송/CS | 주인공을 "오배송"으로 밀반입한 장본인 (3막 공개) |
| 「감성의 뮤즈」 | 감성/디자인 | [[답글없는사장|모겁 무응답]]을 몰락시킨 한 줄 리뷰의 주인 |

용어 규칙: "신"은 필멸자 구어로만, "운영자"는 3막 반전 전 금지 ([[용어사전]]).
