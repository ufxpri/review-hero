# 4계열의 세계관적 근거

> 정본: worldview-v1.0.md §3

원리: 마법이 따로 있는 게 아니라, **[[만물대장]]의 4개 평가 카테고리가 4대 원소를 대체했다.**

| 계열 | 속성 | 세계관 근거 | 계열을 세운 [[만물체험단|단원]] |
|---|---|---|---|
| 품질/마감 | 물리 | 물질의 결합력은 품질 평점이 유지한다. "마감이 부실하다"는 팩트는 분자 결합에 대한 이의제기 → 실제로 헐거워진다 | 「검수관」 |
| 성능/최적화 | 마법 | 마법 = 만물대장의 연산 자원(마나) 대여. 성능 리뷰는 대여 효율 감사 → 출력 저하·연비 악화 | 「최적화의 현자」 |
| 배송/CS | 시공간·CC | **모든 이동·소환은 물류다.** 워프 = 특급배송, 소환수 = 구성품, 부활 대기 = 배송 지연. 배송 리뷰는 시공간 좌표 클레임 → 지연·봉인·캔슬 | 「택배좌」 |
| 감성/디자인 | 정신 | 존재는 "어떻게 보이는가"의 평가로 자아를 유지한다. 감성 리뷰는 자아상 직격 → 의지 데미지가 유독 잘 박힌다 | 「감성의 뮤즈」 |

## 적 특성의 서사 근거

- E04 도적 "은신 중 배송/CS만 명중": 은신 = 좌표 은폐. 좌표 없는 대상의 품질·감성은 평가 불능, 물류 클레임만이 좌표를 강제 조회한다
- E05 나르시시스트 기사 "감성 데미지 ×2": 자아를 외부 평가로만 지탱하는 존재의 극단적 감성 의존
- 버프 리뷰의 회복 근거: 5성 리뷰는 **자기 장비**에 다는 것 — 장비가 의지를 북돋운다 (툴팁 표기)

원소 상성은 없다: 카테고리는 서로 간섭하지 않는 독립 평가축 ([[ADR-001-원소상성-보류]]).
