## 1. 비주얼 컨셉 — 「만물마켓」

**게임 UI 전체가 쇼핑몰/리뷰 앱의 인터페이스다.** 판타지 UI(양피지·검·마나바)를 쓰지 않는다. 플레이어는 던전을 도는 게 아니라 **커머스 앱을 쓰고 있고**, 그 앱이 어쩌다 판타지 세계일 뿐이다.

이 방향을 택한 이유:
1. **테마 = 메커닉 = UI의 3중 일치.** 리뷰가 무기인 게임에서 "리뷰 작성 폼"이 곧 전투 인터페이스가 된다. 설명이 필요 없다.
2. worldview §5 톤 원칙 **"세계는 진지하고, 그 세계의 규칙이 웃기다"** 를 UI가 직접 구현한다. 화면은 진지한 커머스 앱이고, 거기 올라온 상품이 오크일 뿐 — 아무도 웃기려 하지 않는다.
3. 1~2인 개발 규모에 맞는 아트 부담. 캐릭터 일러스트 없이도 성립하고, 나중에 상품 썸네일만 교체하면 비주얼이 올라간다.

### 대응 사전 (게임 개념 → 커머스 표현)

| 게임 | 화면에 보이는 것 |
|---|---|
| 적 | 상품 (상세 페이지) |
| 적 의지/체력 | 존재 등급 ★ + 리뷰 수 |
| 적 티어 | 판매자 등급 (일반 셀러 / 파워 셀러 / 본사 직영) |
| 적 인텐트 | **발송 예정** 알림 (📦 곧 도착합니다) |
| 적 장비 | 구성품 |
| 무효 태그 | **평가 불가 항목** (경고색 칩) |
| 리뷰 제출 | 리뷰 작성 폼 (별점 + 본문) |
| 필력 | ✍ 작성 가능 횟수 |
| 신뢰도 게이지 | 리뷰어 등급 진행바 (★ 10칸) |
| 크리티컬 리뷰 | **이 라운드 베스트 리뷰** (리뷰 1건에 붙는 표식 — 사람 칭호 「베스트 리뷰어」와 구분) |
| 항복 | 판매자 폐업 |
| 승리 | 구매 확정 |
| 패배 | **회원 탈퇴 처리** |
| 맵 노드 | 카테고리 / 배송 경로 |
| 상점 | 진열대 |
| 휴식 | 고객센터 |
| 카드 보상 | 적립 쿠폰 |
| 덱 | 내가 쓴 리뷰 목록 |
| 유물/영구 강화 | 멤버십 등급 혜택 |

### 컬러·타이포·모션

- **컬러**: 커머스 앱의 관용색을 그대로 쓴다 — 종이빛 배경(#F7F6F3), 흰 카드 패널, **커머스 레드**(#E8482B, CTA·경고·적 체력), 별점 골드(#F5A623), 링크 블루(#2E6ED9, 선택·필력). 판정 색은 의미색으로 분리: 팩트=그린, 헛소리=레드, 일반=회색. 다크 모드는 별도 스텝으로 설계(자동 반전 금지).
- **타이포**: 시스템 한글 산세리프(Pretendard/Apple SD Gothic Neo). 장식 폰트 없음 — 앱처럼 보여야 한다. 숫자는 `tabular-nums`. 예외 하나: **만물대장·만물체험단 관련 텍스트만 명조체** (세계관의 "장부" 레이어를 활자로 구분).
- **모션**: 앱의 관용 동작만. 카드 선택 = 살짝 떠오름, 제출 = 리뷰가 목록에 **추가되는** 애니메이션, 크리티컬 = 리뷰가 "베스트"로 **고정(pin)** 되는 연출, 사망 = 탈퇴 확인 모달. 판타지 이펙트(폭발·번쩍임) 금지.
- **사운드**(후순위): 알림음, 키보드 타이핑, 결제 완료음, 카트 담기음.

### 금지 사항

판타지 UI 프레임·양피지·픽셀아트·검과 마법 아이콘 / 실존 서비스의 식별 가능한 UI 모방(색·로고·레이아웃 — worldview §5.2 R17) / 캐릭터가 자기 세계를 개그로 자각하는 텍스트.

## 2. 화면 인벤토리 (전체)

우선순위: **P0** = MVP(Layer 1) 필수 · **P1** = Layer 1.5~2 · **P2** = Layer 3~4.

### 2.3 전투 (P0) ★ 코어

| # | 화면 | 구성 |
|---|---|---|
| S20 | **전투 = 상품 상세 페이지** | ①상단바(계정 스탯: 의지🧠·필력✍·골드🪙) ②상품 히어로(썸네일·존재 등급★·의지바·평가 불가 칩) ③**발송 예정 알림**(적 인텐트) ④구성품 리스트(탭=대상 지정) ⑤내 계정 카드(신뢰도 ★10칸·성향·내 장비) ⑥댓글창(전투 로그) ⑦하단 고정 손패 + 리뷰 작성 폼(접두+접미 조합 미리보기 + 판정 예고) |
| S21 | 판정 피드백 | 제출 시 리뷰가 목록에 추가되며 **팩트!/일반/헛소리…** 배지. 헛소리는 원인 1줄("이 대상엔 [연비] 항목이 없습니다") |
| S22 | 크리티컬 연출 | "이 라운드 베스트 리뷰로 고정되었습니다" — 리뷰가 상단에 pin되는 모션 + 성향별 문구 |
| S23 | 전투 종료 모달 | 구매 확정 / 판매자 폐업(항복) / 회원 탈퇴(패배) / 주문 취소(이탈) |

**설계 규칙**: 전투 화면은 스크롤되는 상품 페이지, 손패는 하단 고정 시트. 모바일 세로 우선(최대 폭 760px) — 이 게임은 한 손으로 스크롤하며 읽는 게임이다.

## 3. 구현 로드맵 (화면 기준)

| 단계 | 화면 | 상태 |
|---|---|---|
| **프로토타입** | S20~S23 전투 + 임시 상품 목록 | ✅ **완료** — `prototype/index.html` |

| MVP-2 | S01·S02·S10·S14 셸, S31 상점, S32·S33 노드 | |

## 4. 프로토타입 현황

`prototype/index.html` — 빌드: `node packages/proto/build.mjs`, 검증: `node packages/proto/smoke.mjs`

포함: 상품 목록(적 6종 선택) · 전투 전체(S20~S23) · 접두+접미 조합과 판정 예고 · 태그/평가 불가 칩 · 대상 지정(구성품·내 장비) · 특수 카드(무료 나눔 증정 포함) · 퇴고 · 크리티컬 · 전투 로그 · 결과 모달.

미포함(다음 단계): 맵·보상·상점·런 진행, 사운드, 모션 연출, 다크모드 정밀 조정.
