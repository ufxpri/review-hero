# 이세계 리뷰용사 — 전투 모델 v0.1

카드 데이터(cards-v0.1.yaml)와 적 데이터(enemies-v0.1.yaml)가 전제하는 전투 규칙.
숫자는 전부 초안이며, 프로토타입 테스트로 조정한다.

## 기본 구조

- 턴제. 플레이어 선공.
- 플레이어: **의지 30** (HP에 해당), 매 턴 **에너지 3**, 드로우로 **손패 5장** 유지.
- 적: **의지** + **장비 1~3개**(각각 내구도와 태그 보유) + 행동 패턴(인텐트 공개).

## 리뷰 제출 (카드 플레이)

- 기본 플레이 = **접두 카드 1장 + 접미 카드 1장**을 조합해 한 문장의 리뷰로 제출.
  - 비용 = 접두 비용 + 접미 비용.
  - 접미 단독 사용 불가(문장이 성립하지 않음). 접두 단독도 불가.
- **특수 카드**는 완성형 문장이므로 단독 사용.
- 타겟 규칙:
  - 의지 데미지 계열 접미 → 적 본체.
  - 장비 계열 접미(내구도, 비활성 등) → 적 장비 중 1개 지정.
  - 버프 계열 접미 → 내 장비 또는 나 자신.

## 태그 판정 (핵심 룰)

접두 카드에는 태그가 1개 붙어 있다. 대상(적 장비/본체)의 태그와 비교해 판정한다.

| 판정 | 조건 | 효과 배율 | 신뢰도 게이지 |
|---|---|---|---|
| **적중 (팩트)** | 접두 태그 ∈ 대상 태그 | ×1.5 | +2 |
| **일반** | 태그 무관 | ×1.0 | 0 |
| **헛소리 (억지)** | 접두 태그 ∈ 대상 무효 태그 | ×0.5 | −2 |

- 무효 태그 예: 나무 몽둥이에 "배터리가…" → 헛소리 판정.
- 같은 턴에 같은 계열 리뷰를 연속 제출하면 두 번째부터 게이지 +1 추가 (계열 콤보).

## 신뢰도 게이지

- 0~10. 전투 시작 시 0. 전투 간 유지되지 않음.
- **10 도달 시 [크리티컬 리뷰] 사용 가능** (게이지 전부 소모, 에너지 0):
  - 팩트 폭격기 성향: 방어·저항 무시 고정 20 데미지.
  - 프로 불편러 성향: 적 전체 기절 1턴 + 골드 갈취.
  - 힙스터 평론가 성향: 적 공격력 영구 −50% (가스라이팅).
  - 바이럴 앞잡이 성향: 현재 내 버프 효과 전부 2배.
- 성향은 런 중 계열별 카드 사용 횟수 통계로 자동 결정 (최다 사용 계열).

## 승패

- 적 의지 0 → 승리.
- 적 장비를 전부 파괴하면 적은 해당 행동을 쓸 수 없게 되어 [항복] (전투 승리, 보상 감소 없이 시간 단축 루트).
- 내 의지 0 → 패배. 보스전 패배 시 [보스 리뷰 남기기] (비동기 시스템, Layer 3).

## 계열 ↔ 태그 매핑

| 계열 | 대응 판타지 속성 | 소속 태그 |
|---|---|---|
| 품질/마감 | 물리 | 마감, 내구도, 무게 |
| 성능/최적화 | 마법 | 출력, 연비, 이펙트 |
| 배송/CS | 시공간/CC | 속도, 구성품, 응대 |
| 감성/디자인 | 정신 | 디자인, 감성, 개연성 |

## 밸런스 기준선 (v0.1)

- 플레이어 평균 화력: 턴당 8~12 (에너지 3으로 조합 1~2회).
- 일반 적은 2~4턴, 정예는 5~6턴, 보스는 8~10턴에 잡히도록 의지 설정.
- 적 화력: 일반 적 턴당 4~6, 플레이어가 5~6턴 안에 못 끝내면 위험해지는 수준.
