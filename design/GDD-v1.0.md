## 0. 확정 사항 (불변)

- 장르: 리뷰가 공격·경제·성장 수단인 텍스트 중심 로그라이크 덱빌더. 싱글 코어 + 비동기 온라인. 1~2인 개발. 한국어 특화.
- 전투: **리뷰 카드 1장 = 완성 리뷰 제출**(태그 1개 단일 초점, 대상 우선 지정 — 정본: card-system-v2.md). 판정 4단계: 원산지 ×1.5+1/게이지+4·무효 태그 무시, 팩트 ×1.5/게이지+3, 일반 ×0.9, 헛소리 ×0.5/게이지−2. 게이지 10 → 논점별 크리티컬 리뷰.
- 4계열: 품질/마감(물리), 성능/최적화(마법), 배송/CS(시공간·CC), 감성/디자인(정신). 원소 상성 없음(태그 적중/무효로만 표현).
- 경제: 리뷰 네고(악평 할인 + 런 지속 페널티, 런 종료 시 소멸).
- 비동기: 보스 디버프 리뷰 공유(슬롯 5, 구매 인증, 배당, 사장님 답글) + 유언·전단지.
- UGC: 등록 시점 LLM 1회 판정. 전투 중 실시간 LLM 금지.
- 개발 순서: Layer1 전투 → Layer2 네고 → Layer3 비동기 → Layer4 UGC. 서버 = 단순 CRUD 수준.

## 1. 제품 정의·개발 로드맵·MVP 컷라인

### 1.1 기술 스택 (확정)

- 클라이언트: **Godot 4 + C#(.NET 8)** (ADR-029). 전투 규칙은 **Godot 무의존 클래스 라이브러리**(`engine/`)로 분리 — 렌더러 교체 가능성과 서버 리플레이 검증(§8)의 전제인 시드 결정성을 위해서다. Unity 배제.
- **C# 인 이유**: 밸런스 도구(`sim/` 시뮬레이터 · `engine.tests/` 65개)가 엔진과 같은 언어여야 살아남는다. GDScript 로 쓰면 시뮬을 버리거나 엔진을 두 벌 유지해야 하고, 후자는 규칙 드리프트를 부른다(ADR-025·029).
- **배포: 데스크톱 전용** — macOS·Windows·Linux (ADR-030). **웹 내보내기는 Godot 4 + C# 이 지원하지 않는다** — C# 을 택한 대가다. 공유는 URL 이 아니라 실행 파일 전달이다.
- 구 TS 스택(`packages/*`·`ui/game/*`)은 Godot 이 프롤로그·도감·업적·설정을 갖추고 밸런스 라운드 2가 끝날 때까지 **동결 상태로 병존**한다 — 새 기능은 Godot 에만 넣는다(ADR-030).
- 서버: **Firebase** — Auth(구글 로그인), Firestore(데이터), Cloud Functions(검증·LLM 프록시·정산), Cloud Scheduler(배치). Realtime DB·Storage 미사용. 보안 규칙: 본인 문서만 쓰기, 읽기는 공개 컬렉션. (ADR-008)
- 운영비 상한: 서버 ~$25/월 + LLM $50/월 = 월 약 10만원.

## 2. 공통 계산 규칙

1. 모든 배율은 **내림, 최소 1**. (3딜×1.5=4, 5딜×0.5=2)
2. 신뢰도 게이지 **0~10, 초과 소실, 하한 0**. 전투 시작 0(외부 보정 제외), 전투 간 미유지.
3. 에너지(UI 표기 **"필력"**, 이하 규칙 서술은 편의상 에너지): 턴당 3, 이월 없음. S15는 다음 턴 가산.
4. **런 시작 외부 보정 총합 캡(R20)**: 비동기·메타 유래 보정은 시작 게이지 +3, 시작 골드 +30, 보스 디버프 위력 합산 +50%를 초과 불가.
5. **계열 콤보 없음** — 게이지 소스는 §3.4의 표가 전부다.
6. 용어는 worldview-v1.0.md §6 용어 사전이 정본. 코드·문서는 사전 키를 참조한다(문자열 하드코딩 금지 — "필력" 채택 조건).
7. **피해의 인게임 명칭은 「좋아요」다**(worldview §1.1 호응 원칙 · §6 · ADR-015). 규칙 서술은 편의상 '피해'로 적되, **UI·플레이버·연출 텍스트는 예외 없이 「좋아요」를 쓴다.**

**좋아요 환산식 (모든 피해의 단일 경로):**

```
최종 좋아요 = ⌊ 기본 좋아요 × 판정 배율 × 기타 배율(버프·상성·기믹) ⌋ + 고정 가산
             (규칙 1 적용 — 내림, 최소 1)
```

- **기본 좋아요** = 카드에 인쇄된 수. 아직 아무도 누르지 않은 잠재치이며 UI에서 **빈 👍**로 표시한다.
- **최종 좋아요** = 환산 결과. 실제로 눌린 수이며 **채워진 👍**로 표시하고, 이 값이 의지·내구도를 깎는다.
- 배율은 전부 곱한 뒤 **한 번만** 내린다(중간 내림 금지 — 원산지 ×1.5와 버프 ×1.5가 겹칠 때 오차 방지).
- **고정 가산은 내림 뒤에 더한다**(원산지 +1, X05 가산 등). 배율의 영향을 받지 않는다.
- 적의 공격도 같은 단위다. 적의 리뷰가 받은 좋아요가 플레이어의 의지를 깎는다.

## 3. 전투 시스템 (Layer 1)

### 3.1 기본 수치

- 플레이어: 의지 30, 에너지 3/턴, 손패 5장 유지(상한 8장, 초과분 드로우 중단·소멸 없음), 손패 유지형.
- 적: 의지 + 장비 1~3개(내구도·태그) + 인텐트 공개 패턴.
- 전투 길이 기준선: 일반 2~4턴 / 정예 5~6턴 / 보스 **6~7턴**. 플레이어 화력 **턴당 좋아요 8~12**. 적 화력 일반 4~6.

### 3.2 턴 시퀀스 (01 §1 승계 + 수정)

```
[전투 시작] 셔플 → 5장 드로우 → 게이지 = 0 + 외부 보정(캡 +3) − 감성 악평 페널티 p → 인텐트 공개
[플레이어 턴]
 1. 턴 시작: 내 도트 발동·만료, 예약 효과(X05)
 2. 드로우: 5장까지
 3. 에너지: 3 + 보정
 4. 플레이: 리뷰 제출(대상 지정 → 리뷰 카드 1장) / 특수 / X06 설치 / **퇴고(필력 1 — 손패 1장을 버리고 1장 드로우. 턴 제한 없음, 뽑을 카드가 없으면 불가)**. 크리티컬은 별도 버튼(에너지 0, 게이지 전량, 턴당 1회)
 5. 턴 종료 선언
[적 턴]
 6. 행동: 인텐트 순서 실행. X01 지연 시 스킵. 공격 선언 시 X06 대기 중이면 자동 발동
 7. 정리: 지속효과 tick, 기믹 카운터, 다음 인텐트 공개
```

- **기절 규칙**: 기절한 적은 그 턴 type: attack/buff/steal/stealth 행동 불가. **type: gimmick(사장님 답글 등)은 기절 무시하고 발동**. 기절에서 깨어난 적은 **1턴간 경직 내성(기절·지연·장비 비활성화 면역)** — 기절 무한 락 봉쇄.
- **장비 비활성 봉인**: 활성 장비가 하나도 없는 적은 그 턴 비(非)기믹 행동이 봉인되며, 봉인 불발된 적은 재활성 후 1턴간 경직 내성을 얻는다 — 매턴 재시전 무한 락 봉쇄.
- **퇴고**: 원하는 태그·원산지를 사냥하는 손패 교체 도구(card-system-v2 §7). 재화·판정과 무관한 범용 행동.
- **은신 게이트와 카드 종별**: 크리티컬 리뷰도 "리뷰"이므로 E04 은신 게이트를 적용받는다(적을 향하지 않는 「바이럴 확산」 제외. 배송 크리는 명중+은신 해제). 특수 카드는 리뷰가 아니므로(무판정) 게이트 비대상.
- X06 리액션: 01 §1.1 그대로 (설치형, 대기 슬롯 1, attack에만 발동, −50% 후 피해의 50% 반사, 전 히트 적용·1회 소진).

### 3.3 태그 판정 — 4단계

| 판정 | 조건 | 좋아요 배율 | 추가 | 게이지 |
|---|---|---|---|---|
| **원산지** | 제출 대상이 카드의 `origin`과 일치 | ×1.5 | **고정 좋아요 +1, 무효 태그 무시** | **+4** |
| 팩트 | 카드 태그 ∈ 대상 태그 | ×1.5 | — | **+3** |
| 일반 | 무관 | **×0.9** (v1.3) | — | 0 |
| 헛소리 | 카드 태그 ∈ 대상 무효 태그 | ×0.5 | — | −2 |

- **원산지 = 그 대상에게서 태어난 리뷰**(직접 이겨서 얻은 카드). 판정 범위(`enemy`/`equipment`), 영구 미발동 카드(전생 Z·특수 X·P 해금), 잠정 수치와 튜닝 레버 지위는 **card-system-v2 §2가 정본**.
- **무효 태그는 적 검사 UI에 "평가 불가 항목" 라벨로 전 구간 상시 노출한다**(숨김 정보 아님 — 읽고 겨냥하는 게임). 헛소리 발생 시 피드백 1줄: "이 대상엔 [연비] 항목이 없습니다."
- **찬양 리뷰(★4~5, 버프 계열 — card-system-v2 §6)는 반드시 내 장비 1개를 대상으로 지정**한다. 카드 태그 vs 내 장비 태그로 동일 판정. 적중 시 수치 ×1.5(내림)+게이지 +2. **온보딩 1판 한정 찬양 리뷰는 무판정(항상 일반)**, 2판부터 판정 개방.
- 다중 히트 카드의 판정·게이지는 히트당 적용하되, **버프 가산은 "제출당 1회"만 적용**(히트당 아님).

| **원산지 판정** | **+4** | 헛소리 판정 | −2 |
| 팩트 판정 | **+3** | E05 찬양 강요 | −1 |
| X08 별점 구걸 | +3 (cards-v2.0 정본) | 크리티컬 사용 | 전량(−10) |

| 재반박 성공(L3) | +1 | | |
| 감성 디버프 리뷰(L3, 캡 +3) | +1~3 | | |
| 티어 혜택(L3 v1.1, 캡 내) | +1 | | |

> 카드 게이지 효과는 cards-v2.0.yaml `effect.gauge`가 정본이다.

기대 수급(판정 1.8회/턴): 표준(적중50%/헛소리10%) +1.44/턴 → 보스전 7턴째 크리 1회. 숙련(75%/5%, 판정 2.0) +2.8/턴 → 4턴·8턴 크리 2회. 억지(30%/25%) +0.2/턴 → 0회. **목표: 크리 = 정예·보스전 이벤트. 적중 게이지가 1순위 튜닝 레버.**

### 3.5 크리티컬 리뷰 (게이지 10, 에너지 0, 턴당 1회)

> **UI 표기는 「이 라운드 베스트 리뷰」다** — 그 라운드에서 좋아요를 가장 많이 받은 리뷰라는 뜻이다.
> 리뷰 1건에 붙는 한시적 표식이며,
> 최종 보스의 직함 「베스트 리뷰어」(사람)와 층위가 다르다(worldview §1.2·§6).
> 플레이어가 매 전투 표식을 모으는 행위가 엔딩 B로 가는 예행연습이라는 회수가 여기서 시작된다.

**논점은 사람이 아니라 화제다** — 이번 전투에서 무엇을 물고 늘어졌는지를 가리키며, 그 화제에서 나오는 행위가 크리티컬 리뷰다.

| 계열 | 논점 | 크리티컬 명칭 | 효과 | 확정 수치 |
|---|---|---|---|---|
| 품질/마감 | 품질 논점 | 팩트 폭격 | 방어·저항 무시 **고정 좋아요** | 20 |
| 성능/최적화 | 성능 논점 | 힙스터 인증 | 적 공격력 −50% **디버프 부착**(사장님 답글의 반박 대상 — 카운터플레이 존재) | 전투 내 지속 |
| 배송/CS | 배송 논점 | 진상 접수 | 전체 기절 1턴 + **다음 행동 위력 −50%** + 골드 갈취 | 갈취 일반 8G / 정예 15G / 보스 25G — **갈취만 전투당 1회**, 기절·위력 감소는 크리마다 |
| 감성/디자인 | 감성 논점 | 바이럴 확산 | 현재 내 버프 효과 2배. **버프 0개면 대신 +3 가산 버프 1개 즉시 부착**(바닥 보장, 부착 슬롯 미점유) | **가산 버프 합산 상한 +12.** 크리 2회 중첩·바닥 버프 포함 상한 공유(승산 폭주 봉쇄) |

논점 결정: 낸 리뷰 카드의 계열(`suit`) 누적 카운터 argmax (특수 카드는 무판정·무계열이라 불산입). 동률 = 최근 제출 계열(동률군에 최근 제출 계열이 없거나 null이면 품질→성능→배송→감성 선언 순), 초기값 = 품질 논점. **전투 시작 시 스냅샷 고정.** 논점 UI(아이콘·카운터·맵 배지)는 **2판부터 해금** — 1판은 "필살 리뷰 준비 완료" 버튼 하나로 축약.

## 4. 런 구조·메타 (Layer 1~1.5)

### 4.1 런 골격

3막 × 6층(일반 5+보스 1) = 18노드. 층당 노드 2~3 분기, 층당 1개 방문. 보스 직전 층은 휴식(1.5 이후: 또는 게시판) 보장. **MVP는 1막만.**

노드 가중치(%): 05 §1.2 표 승계. 단 MVP는 게시판 슬롯을 이벤트로 대체. 동일 유형 3연속 리롤. 목표 플레이 타임: 풀 런 20~30분, MVP 1막 런 8~12분.

### 4.2 재화 — 2계통 확정 (R03)

> **메타 진행의 서사 근거(worldview §1.7).** 해금으로 늘어나는 것은 수치가 아니라
> **쓸 수 있는 말의 수**다. 위력은 좋아요가 정하고 좋아요는 대상에 정확히 들어맞는 말에 눌리므로,
> 표현이 모자라면 어떤 대상 앞에서도 두루뭉술해지고 두루뭉술한 글은 눌리지 않는다.
> **앞선 원정대원들이 실패한 이유가 이것이며, 플레이어가 카드를 늘리는 행위가
> 곧 주인공이 그자에게 닿는 유일한 길이다.**

| 재화 | 용도 | 소스 | 싱크 |
|---|---|---|---|
| **골드** | 런 화폐 (런 종료 시 소멸) | 전투 15G(일반)/24G(정예)/보스 50G(1막), 항복 +6G, 갈취, 판매, 이벤트 | 카드 25/45G, 제거, 포션 12G, 회복 25G, 장비 60/90G(L2), 진열대 25~45G(L3) |
| **명성(RP)** | 명예·노출·랭크 (시즌 12주, 30% 이월) | 보스 +10/막, 클리어 +30, 사망 시 **신규 최고 도달 막 갱신 시에만** 막×5, 슬롯 유지 +2/일, 배당 +1/처치, 유언 좋아요 +2(일 상한 20), UGC 채택 +3(일 상한 30) | 랭크 문턱, 시즌 감가 |
| **적립금(P)** | 카드 해금 (Layer 1.5). 인게임 표기 **「협찬 수령」** | 막 +8, 클리어 +15, 정예 +2, 온보딩 +5 | 해금 트리 375P + X09 40P. 완주 후 장기 싱크는 코스메틱 트리(v1.1) |

> **협찬 수령 규칙 (서사 정합).** P로 해금한 카드에는 **원산지 보너스가 영구히 붙지 않는다**
> — 전생 카드(Z01~Z12)와 같은 취급이다. 겪지 않고 돈으로 얻은 리뷰이기 때문이다.
> 이것은 주인공을 죽인 바로 그 짓(협찬 = 안 겪고 쓴 리뷰, worldview §2.1)이며,
> **"돈으로 산 리뷰는 끝내 팩트가 되지 못한다"** 를 규칙 한 줄로 성립시킨다.
> 원산지 보너스는 오직 직접 이긴 대상에게서만 얻는다(card-system-v2 §2).

**계정 골드 없음.** 배당은 P로 지급(10G→1P 환산, 일 상한 30P). RP 지급 단일표는 본 표가 소유한다.

- 1막 수지(R01 재산정): 수입 ≈ 일반 3×15 + 보스 50 + 이벤트 10 + 갈취 8 ≈ **110G**, 상점 1회 지출 기대 60~90G. 풀 런 수입 ≈ 340~360G / 싹 250~400G.
- 휴식 노드: 의지 **30%** 회복 or 카드 1장 무료 제거, 택1(R09).
- 리뷰어 랭크 4티어·주간 시드·시즌: **Layer 3 v1.1.** UGC/좋아요 자격 게이트는 **"첫 보스 처치 계정"** 단일 조건.

### 4.3 유언·업보

- 유언 작성: 모든 사망 시 가능(Layer 3, 템플릿만). **좋아요 보상 집계는 "그 런에서 전투 승리 1회 이상"인 런의 유언만**(자살 파밍 차단 — 악용 #8).
- 업보 노드·카드 봉인·공양: **출시 후로 연기.** 도입 시 업보 승리 골드는 사망 막 비례(1막 +12G / 2막 +21G / 3막 +30G), 공양 반환 카드는 해당 런 사용 불가.

### 4.4 온보딩 — 1판 개념 11개로 다이어트 (UX 검증 채택)

> **선행 단계 — 만물대장 리뷰어 등록(슬라이드쇼 종료 후 서명 페이지 S05).** 개념 카운트에 넣지 않는다.
> **이름과 서명을 한 페이지에서 함께 받는다**(ADR-020·022) — 슬라이드쇼에는 입력을 끼우지 않는다. 플레이어가 적어 넣는 필명이 만물대장에 올라가는 작성자명이며,
> **이 세계의 이름을 쓰면 되받아 맞는다**는 것이 주인공이 살아남는 유일한 근거다
> (worldview §2.1·§2.2, ADR-016·019).
> **둘의 역할이 다르다** — **이름은 사람들이 보고**(리뷰어를 구분하는 표지),
> **서명은 대장이 대조한다.** 서명은 **올리는 행위 그 자체**이며 독자는 보지 않는다.
> 그래서 전투에서 카드에 서명하는 모션이 곧 「게시」다 — 서명이 그어지는 순간 그 리뷰가 올라간다.
> 저장 위치 `localStorage['reviewhero.penname']` · `['reviewhero.sig']`.
> 이후 모든 화면이 이 이름을 부르고 모든 카드 하단에 이 서명이 그어진다.

| 판 | 도입 개념 | 보정 |
|---|---|---|
| **1판** | 대상 지정→카드 1장 제출 → 팩트/일반(첫 전투 무효 태그 없는 E01 변형) → 헛소리(원인 1줄 표시) → 게이지 → 크리(논점 고정, "필살 리뷰" 버튼). 원산지는 별도 주입 없이 첫 카드 보상에서 자연 도입 — 시작 덱은 전생 카드 전량이라 미발동(card-system-v2 §1·§2) | 적 공격 ×0.75, 헛소리 −2→−1, 보스 약화판(의지 45, 야근 강요 미사용), 찬양 리뷰 무판정, 논점 UI 미노출, 항복 미도입 |
| **2판** | 항복(E02에서 자연 발견) → 버프 태그 판정 → 정예 → 논점 UI | 적 공격 ×0.9 |
| **3판~** | 정상 난이도. 이후 레이어 도입 순서: 네고(L2) → 게시판·보스 리뷰·유언(L3) → UGC(L4) | 없음 |

## 6. 비동기 (Layer 3)

03 문서를 다음 수정과 함께 승계한다. v1 범위: 슬롯 경쟁·좋아요·사장님 답글·유언. **배당·전단지·주간 시드는 v1.1.**

### 6.1 작성권 — 패배·승리 양쪽에서 발생

| 경로 | 조건 | 가중치 W | 명칭 |
|---|---|---|---|
| 패배 | 깎은 의지 30~59 / 60~89 / ≥90% | 1.0 / 1.5 / 2.0 (Tier 1/2/3) | 구매 인증 / 헤비 유저 / 최후의 증인 |
| **승리** | 처치 | **0.8** (Tier 1 상당 디버프) | **정복 후기(구매 확정)** |

깎은 % 는 누적 가한 피해 기준. 유저당 보스당 주간 1회, 재작성 시 좋아요 0 리셋 + **신선도 F=0**(최초 작성 1회만, E08).

### 6.2 슬롯·점수·디버프

- 슬롯 5개 활성. `score = V×W + F`, F = max(0, 48−경과h)×0.5. 매시 배치 재계산. 창의성 점수는 순위에 불개입(R05).
- 디버프 최종 위력 = `floor(풀 기본치 × Tier계수(0.8/1.0/1.25/1.5) × m(0.85~1.35))`, **절대 상한 = 기본치 ×2.0**. 게시판 좋아요 +10%는 최종값에 1회 곱(R05).
- **동일 계열 디버프는 슬롯 내 1개만 효과 적용**(3번째부터는 표기만 — 악용 #6). 감성(시작 게이지) 총합 캡 +3(R20).
- 좋아요: votes 테이블 PK = (review_id, voter_id) **채널 무관 단일**(E07). **좋아요 집계 자격 = 첫 보스 처치 계정**(악용 #7). 동일 IP/디바이스 클러스터 좋아요 가중 감쇠 + 상호 좋아요 그래프 주간 배치 탐지는 v1.1.

### 6.3 배당 (v1.1)

- 처치당 10G 상당 → **P 환산 지급**(R03). 분배 C_i = W_i×(1+V_i/10).
- **지분 0 처리: killer 본인 + killer와 동일 IP/디바이스 클러스터 계정**(E03 확장, 악용 #2 링 차단). **작성자별 주간 배당 상한** 신설(P 60/주).
- 복수 보너스 ×1.1 유지. 일일 배치 정산.

### 6.4 유언·전단지·게시판·원정대 명단

> **서사 근거(worldview §2.4).** 비동기로 만나는 타 플레이어는 **「환불원정대」의 다른 대원**이다.
> 전원 다른 세계에서 불려 왔고 전원 익명이며, 살아 있는 것은 지금 플레이 중인 자신뿐이다.
> 죽은 대원이 남긴 글을 읽으며 나아가는 구조가 다크소울식 메시지와 그대로 맞물린다.

**원정대 명단 (신규 — Layer 3 v1)**

| 항목 | 표시 | 근거 |
|---|---|---|
| 대원명 | 필명 | 대장에 올라간 작성자명 그대로 |
| 순위 | **명성(RP)** | 대원 본인에게는 별점이 없다 — 그를 향해 쓴 리뷰가 **수취인 불명**으로 붕 떠 한 건도 닿은 적이 없기 때문(worldview §2.6). 명성이 유일한 지표다 |
| 대표 리뷰 | 그 대원이 남긴 최고 좋아요 리뷰 1건 + **그가 매긴 ★** | 별점은 대원이 **받은** 것이 아니라 **매긴** 것이다. 이 구분을 UI 문구로 명시할 것 |
| 상태 | 계류 / 게시 / 유실 | 마지막 글이 올라갔는지 여부. 「유실」은 그자에게 묻힌 경우 |

- 명단 정렬은 시즌 RP 기준이며 §6.2의 좋아요 집계를 그대로 쓴다(별도 채널 금지).
- 주간 라운드 상위 100 = "이주의 체험단"(코스메틱만), 시즌(12주) RP 상위 100 = "차기 후보석"(R12).
- **표기 주의**: 명단·게시판 어디에서도 대원에게 ★를 매긴 것처럼 보이면 안 된다.
  ★ 옆에는 항상 대상(적·구성품)이 붙는다.


- 유언: 템플릿 조합만(v1). 노출 = 03 §2.2(방당 3, 층당 5), 자유문·w 가중은 Layer 4 v1.1(R10). 좋아요 보상 = RP +2(§4.2 단일표).
- 전단지 = "네고 30%+ 성사 시 상점 벽보"(R04). 게시판 ③ = **진열대**, UGC 카드 가격 25~45G(R16). 자기 홍보문은 전단지의 Layer 4 자유문 확장으로 통합.
- 게시판 노드 4섹션 승계, 단 **② 조롱 버튼은 컷**(E09). ①의 좋아요 위력 +10%는 §6.2 좋아요과 동일 votes 행으로 집계(이중 채널 금지).

## 7. UGC (Layer 4)

04 문서를 다음 수정과 함께 승계한다. **v1 = ③ 금지어 팩폭 1구간만.** ② 유언 자유문·④ 전단지 자유문은 v1.1, **① 사기극은 컷(보류)**.

- LLM: claude-haiku-4-5, structured outputs, system ~4,500tok 캐시, 효과는 **고정 풀 select-only + 배율 m**(창작 금지). 태그는 12종 사전 confidence 규칙. 비용 모델·스팸 방어 6종(서명 토큰·쿼터 5건/일·레이트리밋·해시 캐시·첫 보스 게이트·밴 에스컬레이션) 승계.
- **표절 처리(E10)**: 해시 캐시 히트 시 최초 등록자만 원점수, 타 계정은 originality 0 + specificity 절반("표절 리뷰" 연출). LLM 호출 0회 유지.
- 모더레이션: 04 §4 승계, 단 **브랜드 패러디는 06 기준으로 강화**(R17) — "믹도랄드"류 1글자 변형 금지, 식별 불가능한 일반화 치환만 제시.
- 박제: 3중 게이트(90점 + 30일 좋아요률 상위 5% + 주간 수동 큐레이션 3장) 승계, v1.1. 골드 보상 없음 원칙 유지. 큐레이션에 원작자 확인 항목 추가(E10).
- 쿼터 = min(랭크 쿼터, 시스템 상한 5)(R14). 랭크 도입 전엔 상한 5만.

## 8. 서버 신뢰 모델 (악용 #1 — Layer 3 착수 게이트)

클라 보고를 신뢰하지 않는다. Layer 3 v1 착수 전 필수 구현:

1. **서버측 클램프·재계산**: dmg_pct는 0~100 클램프 + cert_tier는 서버가 재계산. best_score·팩트 수는 이론 최대치(런 구조로부터 계산) 초과 시 거부.
2. **작성권 서명 토큰**: 런 결과 요약(시드, 노드 경로, 전투 로그 해시) 제출 → 휴리스틱 정합 검사(소요 시간, 턴 수 하한) 후 발급. TTL 10분.
3. **주간 시드 리플레이 검증(v1.1)**: 시드가 결정적이므로 `시드+입력 로그` 업로드 → Cloud Function이 코어 상태머신(UI 무의존 패키지 재사용)으로 결정적 리플레이. **상위 100 + 무작위 표본만 검증** — 전수 검증·ML 이상 탐지는 하지 않는다(1인 규모).
4. 스키마: 03 §5 승계 + boss_reviews에 `crit_used bool`(R18), 승리 작성권용 `origin('defeat'|'victory')` 컬럼 추가.
