## 1. 두 번의 전환

### 전환 1 — 조합형 폐지 (1장 = 1리뷰)

| | v1 (조합형) | **v2** |
|---|---|---|
| 1회 제출 | 접두 1장 + 접미 1장 | **리뷰 카드 1장** |
| 태그 판정 | 접두가 태그 보유 | **카드가 태그 1개 보유** |
| 카드 본문 | 문장 조각 (`마감이…`) | **완성된 리뷰 2~4줄** |

「마감이…」 + 「…쓰레기네요.」 = **"마감이 쓰레기네요."** — 조합형은 32장으로 256가지를 만드는 구조적 우아함이 있었지만 결과물이 리뷰가 아니라 리뷰 조각이었다. 이 게임은 글이 재미없으면 존재 이유가 없다.

### 전환 2 — 설계 순서 역전 (대상 → 리뷰)

**v1은 범용 카드를 먼저 만들고 적을 나중에 맞췄다.** 그러면 "손잡이가 빠졌습니다" 같은 **어느 상품에나 붙는 무난한 리뷰**만 나온다. 구체성이 없으면 안 웃긴다.

**v2는 리뷰 대상을 먼저 설계하고, 리뷰는 거기서 태어난다.**

```
대상: 초대형 둔기 (오크 구성품 · #무게 #내구도)
  ├ 「손목 나감」    ★1 #무게   "위력은 확실한데 손목이 나갑니다.
  │                              데드리프트 3년 하고 오세요."
  ├ 「무게중심 엉망」 ★2 #무게   "휘두르면 제가 따라갑니다. 무기가 저를 휘두릅니다."
  └ 「들 수가 없어요」★1 #무게   "성인 남성 둘이 들었는데 안 들립니다.
                                 판매자분은 '한 손으로 쓰는 무기'라고 하셨습니다."
```

### 이 역전이 연쇄적으로 푸는 것들

**① 카드 획득이 서사가 된다.** 카드 보상(S30)이 "무작위 3장 중 택1"이 아니라 **"이번 전투에서 쓴 리뷰 중 하나를 내 리뷰 목록에 남긴다"** 가 된다. 오크를 이겨야 오크 리뷰를 얻는다.
> 대장에 올릴 수는 없다 — 그는 대장이 읽지 못하는 존재다(worldview §2.2).
> 그가 가진 건 아무도 인정해 주지 않는 개인 목록뿐이고, **그 목록이 곧 덱이다.**

**② 시작 덱이 해명된다.** 시작 덱 12장 = **전생에 쓴 리뷰들.** 보조배터리·무선이어폰·배달음식·조립식 의자. 이 세계에 없는 물건이라 원산지 보너스가 **영구히 발동하지 않는다** — 시작 카드가 왜 약한지가 세계관으로 설명되고, 주인공이 이 세계 물건을 리뷰하며 강해지는 것이 성장 곡선 그 자체가 된다.

> 주인공은 협찬 받은 미인증 보조배터리의 후기를 쓰던 중 그 제품의 폭발로 죽었다(worldview §2.1).
> 그 보조배터리 리뷰가 시작 덱에 들어 있다.

**③ 리뷰를 읽는 게 정찰이 된다.** 적 상세페이지엔 이미 리뷰가 달려 있고(`fixed_review`), 그게 약점 태그 힌트다. 대상을 먼저 고르는 흐름이라 이게 자연스러워진다 — **상품 페이지 스크롤 → 기존 리뷰 읽기 → 약점 파악 → 내 리뷰 작성.**

**④ 개그가 한 단계 올라간다.** 엘프 마법사를 **오크 둔기 리뷰를 낭독해서** 공격하게 된다. 실제 인터넷 리뷰어가 하는 짓 그대로다 — 상관없는 옛날 불만을 굳이 끌고 온다.

## 2. 판정 4단계 (원산지 추가)

v1의 3단계 위에 **원산지**를 얹는다.

| 판정 | 조건 | 좋아요 배율 | 추가 | 게이지 |
|---|---|---:|---|---:|
| **원산지** | 제출 대상이 카드의 `origin`과 일치 | ×1.5 | **고정 좋아요 +1**, **무효 태그 무시** | **+4** |
| 팩트 | 카드 `tag` ∈ 대상 `weakness_tags` | ×1.5 | — | +3 |
| 일반 | 그 외 | ×1.0 | — | 0 |
| 헛소리 | 카드 `tag` ∈ 대상 `null_tags` | ×0.5 | — | −2 |

**원산지의 진짜 가치는 배율이 아니라 「무효 태그 무시」다.** 직접 산 사람의 증언은 "평가 불가 항목"이라는 반박이 통하지 않는다 — 만물대장 팩트 원칙(worldview §1.1)의 서사적 근거와 정확히 맞는다.

```
〈손목 나감〉 ★1 #무게 ✍1 · 원산지: 초대형 둔기 / 오크

  · 오크 · 초대형 둔기 → 원산지  👍 7×1.5+1 = 11, 게이지 +4
  · 다른 #무게 적       → 팩트    👍 7×1.5   = 10, 게이지 +3
  · 엘프 (#무게 무효)   → 헛소리  👍 7×0.5   =  3, 게이지 −2

  카드에 인쇄된 7은 「기본 좋아요」, 화면에 뜨는 11·10·3이 「최종 좋아요」다(GDD §2).
```

### `origin` 판정 범위

```yaml
origin: { enemy: E02, equipment: 초대형 둔기 }
```
- **적 본체**를 대상으로 제출 → `enemy`가 일치하면 원산지
- **구성품**을 대상으로 제출 → `equipment`가 일치하면 원산지
- 적 본체에서 태어난 리뷰(`equipment` 없음)는 그 적 본체에만 원산지
- 특수 카드(X##)와 전생 상품 카드(Z##)는 `origin` 없음 → **영구 미발동**
- **P(적립금)로 해금한 카드도 `origin` 없음 → 영구 미발동.** 겪지 않고 돈으로 얻은 리뷰이기
  때문이다(GDD §4.2 「협찬 수령」). 원산지는 **직접 이긴 대상에게서만** 얻는다 —
  주인공을 죽인 것이 바로 안 겪고 쓴 협찬 리뷰였다는 사실이 규칙으로 남는다.

### 밸런스상 의미

레버가 하나 늘었다. 다음 층 보스가 예고되면 **그 보스를 겨냥해 덱을 짜는 메타**가 생기고, 이는 v1에 없던 준비-보상 구조다. 동시에 리스크도 명확하다 — 보스 전용 카드는 나머지 90%의 전투에서 평범해진다. **의도된 트레이드오프이며, 원산지 배율은 밸런스 라운드에서 가장 먼저 조정할 레버다.**

### 기각한 대안 — 「재반박 면역」

보스의 「사장님 답글」이 원산지 리뷰를 반박하지 못하게 하는 안(“직접 산 사람의 말이라 반박 불가”). 서사적으로 매력적이지만 보스전에서만 작동해 밸런스 레버로서 범용성이 없고, 원산지 보너스와 효과가 중복된다. **보류 — 보스전이 너무 쉬워질 경우의 하향 카드로 남긴다.**

### 태그 분포 — 실측치와 1막 커버리지

대상에서 리뷰를 뽑으면 태그가 대상 쪽으로 쏠린다. 균등 배분이 아니라 **실측 결과**를 정본으로 기록한다.

| 태그 | 카드 | 1막 약점 여부 | | 태그 | 카드 | 1막 약점 여부 |
|---|---:|---|---|---|---:|---|
| 응대 | 7 | ○ | | 감성 | 4 | ○ |
| 마감 | 6 | ○ | | 디자인 | 4 | ○ |
| 개연성 | 6 | ○ | | 내구도 | 3 | ○ |
| 속도 | 5 | ○ | | **구성품** | 3 | **✗ 해당 없음** |
| 무게 | 5 | ○ | | **출력** | 2 | **⚠ 무효 태그로만 등장** |
| 연비 | 4 | ○ | | 이펙트 | 2 | ○ |

**확인된 공백 (TBD)**: 1막 적 6종 + 구성품 6종을 통틀어 `출력`·`구성품`을 약점으로 가진 대상이 없다. 해당 카드 5장(Z02·Z04·Z09·Z10·C01c)은 1막 내내 **일반 판정 고정**이며, `출력` 2장은 나르시시스트 기사(E05)의 무효 태그라 **헛소리까지 난다**.

전량 시작 덱·전생 카드라 "빼야 할 잉여 카드"로서 기능하므로 **의도된 열화로 볼 여지가 있다** — 시작 덱이 약한 이유가 세계관과 맞물린다. 다만 이는 판단이 필요한 사안이므로 밸런스 라운드 1(v2)에서 두 안 중 택일한다:
- (a) 유지 — 덱 압축 동기로 활용, 카드 제거 노드의 가치 상승
- (b) 1막에 `출력`·`구성품`을 약점으로 갖는 적을 추가 (일반 적이 E01 하나뿐인 콘텐츠 공백과 함께 해소)

### 이펙트 2장 문제는 문제가 아니다

`이펙트`는 엘프 마법사(E03)의 약점인데 카드가 2장뿐이다. v1이라면 심각했겠지만 v2에선 아니다 — **엘프전에서 원하는 건 `이펙트` 태그가 아니라 E03 원산지 카드**이고, 그건 6장(적 3 + 지팡이 3) 있다. 원산지가 팩트의 상위 호환이므로 태그 희소성이 상쇄된다. 대상 우선 설계가 태그 균등의 압박을 덜어주는 지점이다.

## 4. 카드 스키마

```yaml
- id: W01
  name: "손목 나감"            # 짧고 기억에 남게
  origin: { enemy: E02, equipment: 초대형 둔기 }
  suit: 품질                   # 품질|성능|배송|감성 — 성향 산정 기준
  tag: 무게                    # 판정 태그 1개 (단일 초점 원칙)
  cost: 1                     # 필력 (최소 1 — 5절)
  stars: 1                    # ★ 1~5. 4 이상이면 찬양 = 버프 계열 (6절)
  rarity: basic|common|rare|legendary
  target: enemy|enemy_equipment|my_equipment
  text: |                     # ★ 리뷰 본문 — UI 정본. 이 필드가 게임의 얼굴이다
    위력은 확실한데 손목이 나갑니다.
    데드리프트 3년 하고 오세요.
    저는 안 하고 와서 지금 물리치료 다닙니다.
  effect: { type: damage, value: 7 }
  ui: "의지 피해 7"            # 효과 요약 — 본문과 분리해 본문을 오염시키지 않는다
```

**`tag`는 정확히 1개.** 배열을 허용하지 않는다 — 단일 초점 원칙의 핵심이며, 열면 v1의 P04(태그 2개)처럼 "무조건 좋은 카드"가 다시 생긴다.

## 5. 필력 경제 — cost 0 금지

v1에선 접두가 cost 0이어도 접미 비용이 붙어 제출 1건당 최소 1이 들었다. v2에서 cost 0을 허용하면 손패 5장을 전부 공짜로 던져 필력 3이라는 자원이 무의미해진다.

| 비용 | 역할 | 의지 피해 기준 |
|---:|---|---|
| 1 | 주력. 시작 덱 전량 | 3~7 |
| 2 | 효과 동반 또는 고화력 | 5~9 |
| 3 | 한 방 / 판을 뒤집는 카드 | 12~13 |

필력 3/턴 → **턴당 2~3장.** v1의 제출 1~3건과 같은 템포다.
예외: X03·X07만 cost 0 — 둘 다 의지 피해가 없다.

## 6. ★ 별점 = 카드 역할 (읽기 규칙)

별점은 장식이 아니라 **효과를 예고하는 읽기 규칙**이다.

| ★ | 성격 | 효과 계열 | 대상 |
|---|---|---|---|
| ★1~2 | 악평 | 의지 피해, 내구도 파괴, 기절, 디버프 | 적 / 적 구성품 |
| ★3 | 미지근 | 약한 피해 + 부가 이득(드로우·게이지·회복) | 적 |
| ★4~5 | 찬양 | **버프** — 내 장비 강화, 데미지 증폭 | 내 장비 |

찬양 리뷰가 버프인 근거는 세계관에 이미 있다 — 만물대장 평점 원칙상 좋은 평가는 존재를 강화한다(worldview §1.1). **내 장비에 별 다섯을 박으면 그 장비가 실제로 세진다.**

플레이어는 카드를 열기 전에 별점만 보고 공격인지 버프인지 안다. 60장이 되어도 손패 파싱이 무겁지 않은 이유다.

## 7. 2축 puzzle은 어떻게 살아남나

카드 선택이 1축이 된 대신, **대상 지정**이 두 번째 축으로 남는다. 그리고 v1엔 없던 딜레마가 추가된다.

```
카드 선택 (어떤 태그·원산지)  ×  대상 지정 (적 본체 / 구성품 / 내 장비)
```

> 원하는 **태그**와 원하는 **효과**가 한 장에 묶여 있다.
> 「3주째 답이 없습니다」(#응대, 피해 9)는 보스에게 원산지지만 고블린에겐 평범하다.
> 「손잡이 3주」(#마감, 피해 7)는 고블린에게 팩트지만 보스에겐 평범하다.
> 지금 손에 있는 건 후자뿐이고, 적은 보스다. 그래도 낼 것인가, 퇴고할 것인가.

### 손패 커버리지 (실측 분포 기준)

판정 카드 51장, 손패 5장 기준으로 **해당 전투에서 우위 판정(원산지 또는 팩트)이 가능한 카드를 쥘 확률**:

| 상대 | 우위 카드 풀 | 손패 5장에 1장 이상 |
|---|---:|---:|
| 고블린 (E01 · 마감 6 + 원산지 6) | 12 | **73%** |
| 오크 (E02 · 무게 5 + 원산지 6) | 11 | **70%** |
| 엘프 (E03 · 이펙트 2 + 연비 4 + 원산지 6) | 12 | **73%** |
| 보스 (B01 · 응대 7 + 개연성 6 + 원산지 8) | 21 | **93%** |

이는 **덱 전체를 다 모았을 때의 상한**이다. 실제 런 초반 덱은 전생 12장(원산지 영구 미발동)이라 우위 판정률이 훨씬 낮고, **적을 잡아 그 리뷰를 등재할수록 올라간다.** 이 곡선 자체가 성장 곡선이다.

**매 턴 우위 판정이 나오지는 않는다.** 팩트는 이벤트여야 한다는 밸런스 라운드 1의 결론(ADR-009)과 정합한다.

다만 v1보다 **선택지는 늘었다.** v1 손패 5장 = 접두 2 + 접미 3 → 태그 선택지 2개. v2는 5장 전부가 태그 선택지 → **2.5배**. 교착(접두 0장)은 구조적으로 사라진다.

### 퇴고의 역할 변경

v1의 퇴고(필력 1, 손패 1장 교체)는 **교착 방지 안전장치**였다. v2엔 교착이 없으므로 **태그 사냥 도구**로 승격한다. 카드는 유지하되 설명 문구를 바꾼다.

## 8. UI 흐름 변경 — 대상 우선

```
v1:  손패에서 접두 탭 → 접미 탭 → 조합 미리보기 → 대상 지정 → 제출
v2:  대상 탭 (적 본체 / 구성품 / 내 장비)
       → 손패에서 유효 카드 강조 (원산지 ★ / 팩트 ● / 헛소리 ⚠ 뱃지)
       → 카드 탭 → 제출
```

대상을 먼저 고르므로 **손패 전체에 판정 결과를 미리 표시할 수 있다.** v1은 접두를 고르기 전까지 판정을 알 수 없었다. 읽는 부담이 오히려 줄어든다.

## 9. 엔진 변경 범위 (`packages/core`)

| 대상 | 변경 |
|---|---|
| `submitReview(prefixUid, suffixUid, target)` | → `submitReview(cardUid, target)` |

| `modifier` 적용부 | **전량 삭제** (접두 전용 개념) |

| 카드 보상 로직 | 무작위 3택1 → **해당 전투 대상들의 리뷰 풀에서 3택1** |

**살아남는 것**: 태그 판정, 신뢰도 게이지 0~10, 크리티컬 리뷰 4종, 기절 규칙, 적 인텐트, 사장님 답글, 대상 지정, 퇴고, 적 데이터 전량.

**죽는 것**: 접두 `modifier` 12종, 조합 미리보기 UI, 시작 덱의 접두/접미 하한 규칙(GDD §3.6).
