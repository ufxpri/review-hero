# 이세계 리뷰용사 — 전투 시스템 상세 확정안 (회의 산출물 01)

기준 문서: combat-model-v0.1.md / cards-v0.1.yaml / enemies-v0.1.yaml
v0.1과 충돌하는 항목은 맨 아래 "변경 제안" 절에 분리 기재. 그 외는 전부 확정 사항.

## 0. 공통 계산 규칙 (신규 확정)

- 모든 배율 계산(×1.5, ×0.5, ×2 등)은 **내림, 최소 1**. 예: 3딜 ×1.5 = 4, 5딜 ×0.5 = 2.
- 신뢰도 게이지 범위 **0~10, 초과분 소실**. (10에서 +2 적중 → 10 유지)
- 에너지는 턴 이월 없음. S15의 "+1"은 다음 턴 에너지 단계에 가산.

## 1. 턴 시퀀스 (확정)

```
[전투 시작]
 0. 셋업: 덱 셔플 → 손패 5장 드로우 → 게이지 0 → 적 인텐트 공개

[플레이어 턴]
 1. 턴 시작 단계
    a. 플레이어가 건 도트 발동 (S06 장비 내구도 -2 등), 지속턴 -1, 만료 제거
    b. 예약 효과 적용 (X05 가산 준비 등)
 2. 드로우 단계: 손패가 5장이 될 때까지 드로우. 손패 유지형(턴 종료 시 버리지 않음).
    손패 상한 8장 — 상한 도달 시 드로우 중단(소멸 아님).
 3. 에너지 단계: 에너지 = 3 + 보정(S15 등)
 4. 플레이 단계 (에너지 한도 내 자유 순서·무제한)
    - 리뷰 제출(접두+접미) / 특수 카드 / X06 설치
    - 크리티컬 리뷰: 게이지 10일 때 별도 버튼. 에너지 0, 게이지 전량 소모, 턴당 1회
 5. 턴 종료 선언: 계열 콤보 카운터 리셋

[적 턴]
 6. 적 행동 단계: 인텐트 순서대로 실행
    - X01 지연 상태면 이번 행동 스킵(인텐트 유지, 지연 해제)
    - 공격 선언 시 X06 대기 중이면 자동 발동 (아래 1.1)
 7. 정리 단계
    a. 적 지속효과 tick·만료 처리 (S08 "다음 행동" 류는 소비 시 즉시 제거)
    b. 기믹 카운터 갱신 (사장님 답글 3턴 카운터 등)
    c. 다음 인텐트 공개 → 1로
```

### 1.1 X06 「우리 애가 다쳤잖아요」 리액션 타이밍 (확정)

적 턴 중 실시간 입력은 **없다** (텍스트 게임 페이싱 유지). X06는 **설치형 리액션**이다.

- 내 플레이 단계에 2에너지로 플레이 → "대기 상태"로 등록 (필드에 카드 표시).
- 대기는 발동될 때까지 턴을 넘겨도 유지. **대기 슬롯은 1개** — 이미 대기 중이면 추가 플레이 불가.
- 트리거: **type: attack 행동에만** 자동 발동. 버프·기믹·steal에는 미발동(대기 유지).
- 처리 순서: 공격 선언 → 위력 -50%(내림) → 감소 후 피해 적용 → 그 피해의 50%(내림) 반사.
  예: E01 찌르기 5 → 피해 2 → 반사 1. B01 계약 갱신 베기 8 → 피해 4 → 반사 2.
- 다중 히트 공격은 전체 히트에 적용되며 1회 발동으로 소진 → 묘지.

## 2. 시작 덱과 덱 순환 (확정)

### 2.1 시작 덱 12장

| 구분 | 카드 | 수량 | 채용 이유 |
|---|---|---|---|

| 접미 | S03 …실망입니다. 또 실망입니다. | 1 | 판정 2회 = 게이지 수급 학습 |
| 접미 | S05 …처참합니다. | 1 | 장비 대상 학습 |

접두 5 : 접미 6 : 특수 1. 접두가 전부 0코이므로(P04 제외 풀 전체 경향) 손패 정체는 접미 쪽에서 발생 — 의도된 긴장.

### 2.2 획득·제거·순환 규칙

- **획득**: 일반 전투 승리 = 3택1 보상(스킵 가능, 접두/접미/특수 혼합 제시). 정예 = 4택1, special 필드 보유 카드 가중치 2배. 보스 = 4택1 + 특수 카드 확정 1슬롯. 상점 구매 가능. **X08은 유니크 — 덱에 1장 초과 보유 불가.**
- **제거**: 상점에서 25골드(런 중 회당 +10골드 인상), 일부 이벤트. **덱 하한 10장, 접두 최소 4장·접미 최소 4장** (조합 성립 보장). 덱 상한 없음.
- **순환**: 제출된 접두+접미는 함께 묘지로. 특수 카드도 묘지로(소멸 없음 v0.1). 덱 소진 시 묘지 전체 셔플 → 새 덱, 손패는 유지. X04로 증정한 카드만 전투 동안 제외(전투 후 덱 복귀).

## 3. 플레이어 장비 슬롯 시스템 (확정)

**슬롯 3개: 무기 / 방어구 / 장신구.** 적 장비와 동일 규격으로 통일한다(대칭 규칙 = 학습 비용 절감, Layer 2 네고 재사용).

장비 1개의 데이터 규격:
```
이름 / 태그 1~2개 / 무효 태그 0~1개 / 고정 리뷰 1줄(변경 불가)
부착 리뷰 슬롯 2칸 / 패시브 효과 0~1개
※ 내 장비는 내구도 없음 — 파괴되지 않는다
```

- **버프 접미(S13~S16)는 내 장비 1개를 대상으로 지정**해 제출하며, 접두 태그 vs 그 장비 태그로 동일하게 판정한다. 적중 = 게이지 +2 및 수치 효과 ×1.5(내림) / 헛소리 = 게이지 -2 및 ×0.5. 자기 장비 찬양도 팩트여야 한다.
  - 예: S16 회복 5 → 적중 시 7. S14 드로우 2 → 적중 시 3. S13 +2 → 적중 시 +3. S15는 ×1.5 내림 = +1로 변화 없음(게이지 이득만).
- 지속형 버프(S13)만 부착 슬롯 1칸 점유. 즉발형(S14/S15/S16)은 슬롯 미점유. **네고 페널티(Layer 2)도 같은 부착 슬롯 규격 사용** — 슬롯 2칸이 꽉 찬 장비에는 추가 부착 불가.
- 고정 리뷰는 획득 시점에 사전 작성 텍스트로 부여되며 태그 힌트를 겸한다.

**시작 장비 3종:**

| 슬롯 | 이름 | 태그 | 무효 | 고정 리뷰 | 패시브 |
|---|---|---|---|---|---|
| 무기 | 이세계 보급형 롱소드 | 마감 | 연비 | "★★★ 무난합니다. 근데 마감에 실밥이… 아, 검이었지." | 없음 |
| 방어구 | 물려받은 가죽 갑옷 | 내구도, 무게 | 이펙트 | "★★ 3대째 물려 입는 중. 냄새 빼고 다 튼튼함." | 없음 |
| 장신구 | 위조 인증 목걸이 | 감성 | 출력 | "★★★★ 정품 인증서 포함(손글씨)." | 없음 |

## 4. 신뢰도 게이지 경제 검증 (시뮬레이션)

### 4.1 가정 (명시)

- 턴당 리뷰 제출 1.6회 (에너지 3, 평균 조합 비용 1.8 — 0코 접두+1~2코 접미)
- S03 이중 판정 보정 포함 → 턴당 판정 1.8회
- 판정당 기대 게이지 = P(적중)×2 − P(헛소리)×2
- 계열 콤보(직전 제출과 동일 계열 +1) 기대치: 표준 +0.3/턴, 숙련 +0.5/턴
- X08 순환 기여는 별도(12장 덱 기준 약 4턴마다 +2 → +0.5/턴)는 보수적으로 제외

### 4.3 판독

| 전투 유형 | 길이(v0.1) | A 표준 | B 숙련 | C 억지 |
|---|---|---|---|---|
| 일반 | 2~4턴 | 0회 | 0~1회 | 0회 |

- 숙련자 보스전 크리 2회(팩트 기준 40딜 = 보스 HP의 67%)는 상한으로 허용하되, E05 찬양 강요(-1)·보스급 게이지 압박 행동이 견제 수단. 크리 **턴당 1회 제한**이 폭주 방지 핵심(변경 제안 ①).
- C 시나리오가 사실상 0회 → "억지 리뷰 플레이는 게이지를 포기한다"는 판타지가 수치로 성립.

## 5. 성향 결정 알고리즘 (확정)

### 5.1 계열 → 성향 매핑

| 계열 | 성향 | 크리티컬 리뷰 |
|---|---|---|
| 품질/마감 | 팩트 폭격기 | 방어·저항 무시 고정 20 |
| 성능/최적화 | 힙스터 평론가 | 적 공격력 영구 -50% |
| 배송/CS | 프로 불편러 | 전체 기절 1턴 + 골드 갈취 |
| 감성/디자인 | 바이럴 앞잡이 | 내 버프 효과 전부 2배 |

### 5.2 규칙

1. **집계 대상**: 리뷰 제출 시 사용한 **접두의 계열**만. 런 전체 누적 카운터 4개. 특수 카드·크리티컬은 미집계. 버프 리뷰도 접두 계열로 집계.
2. **성향 = argmax(카운터)**.
3. **동률 처리**: 동률 계열 중 **가장 최근에 제출한 계열** 승 (제출마다 타임스탬프 기록). 런 시작 직후 전원 0일 때 기본값 = **팩트 폭격기** (주인공 기본 성향, 세계관 정합).
4. **스냅샷 고정**: 성향은 **전투 시작 시점에 확정되어 전투 중 불변** — 크리 효과의 예측 가능성 보장. 전투 사이에는 매번 자동 재계산(런 중 변경 가능). 수동 고정 기능은 v0.1 범위 외.
5. **UI**:
   - 전투 HUD: 게이지 옆 성향 아이콘. 툴팁 = 4계열 카운트 막대 + 현재 크리 효과 전문.
   - 맵 화면: "다음 전투 성향" 배지 + 역전까지 필요한 제출 수 표시 (예: "감성 3회 더 쓰면 바이럴 앞잡이").
   - 전투 시작 배너: "이번 전투 성향: 프로 불편러" 1회 노출.

## 6. 크리티컬 리뷰 4종 밸런스 (기대 가치 환산)

환산 기준: 1에너지 ≈ 6 의지딜(S01). 골드 25 ≈ 카드 제거 1회 ≈ 8딜 상당의 런 가치. 적 턴당 화력: 일반 5 / 정예 7 / 보스 8 (v0.1 기준선).

| 성향 | 일반전(잔여 1턴) | 정예전(잔여 3턴) | 보스전(잔여 5턴) | 분산 | 비고 |
|---|---|---|---|---|---|
| 팩트 폭격기 | **20** | **20** | **20** | 없음 | 기준선. 관통이라 방어형 적에 추가 프리미엄 |
| 프로 불편러 | 5 + 골드 | 7 + 골드 | 8 + 골드 ≈ **16** | 낮음 | 준비형 패턴(E02 내려찍기) 캔슬 시 가치 급등 |
| 힙스터 평론가 | 2.5 | 10.5 | 5×8×0.5 = 20~**24** | 높음 | 조기 사용 조건부. 답글 반박 리스크로 실효 ~15 |
| 바이럴 앞잡이 | 0~10 | 5~20 | 셋업(S13×2 적중) 시 +4/리뷰 × 8회 ≈ **22~32** | 최고 | 셋업 없으면 0 — 하이리스크 정체성 |

판독: 보스전 기준 16~24 대역으로 수렴, 팩트 20 기준선 ±20% 이내. 일반전에서 팩트가 압도적이지만 크리는 표준 플레이 시 6턴 필요 → 일반전(2~4턴)에서 뜨지 않으므로 실질 문제 없음. 힙스터의 보스전 지배와 불편러의 골드 미정 수치는 변경 제안 ③④로 해결.
