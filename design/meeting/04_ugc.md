# 이세계 리뷰용사 — UGC 파이프라인 + AI 판정 상세 v0.1

전제: combat-model-v0.1.md / cards-v0.1.yaml / enemies-v0.1.yaml.
원칙(개요 문서 확정 사항): **UGC는 등록 시점 LLM 1회 판정. 전투 중 실시간 LLM 판정 금지.**
추가 원칙(본 문서): **LLM은 "평가·분류"만 한다. 효과(게임 로직)는 창작하지 않는다** — 효과는 서버가 가진 고정 효과 풀에서 선택되고, 점수는 배율로만 작용한다. 수치 폭주·밸런스 붕괴를 원천 차단.

## 1. 작성 구간 4종 — 입력 UI 제약

| # | 구간 | 트리거(작성권 발급 조건) | 형식/템플릿 | 글자수 | 빈도 제한 |
|---|---|---|---|---|---|
| ① | **사기극** (허위 바이럴 의뢰) | 런 중 이벤트 노드. NPC가 "쓰레기템"을 제시하며 찬양 리뷰 의뢰 | 별점 ★5 고정 + 제목 + 본문. 자유 기술 | 제목 15자, 본문 20~80자 | 런당 최대 1회 |
| ② | **유언 리뷰** | 플레이어 사망 시(스킵 가능) | 접두 드롭다운 8종 고정("이 던전은…", "이 방의 함정은…" 등) + 자유 본문 + 별점 1~5 | 본문 10~60자 | 사망당 1회 |
| ③ | **금지어 팩폭** (보스 디버프 리뷰) | 보스전 패배 + **보스 HP 30% 이상 감소(구매 인증)** | 자유 본문. 태그는 유저가 선택하지 않음(LLM 부여) | 20~100자 | 보스 패배당 1회 |
| ④ | **전단지** | 명성 1,000 달성 시 해금 | 제목 + 본문(자기 과시/홍보문) | 제목 12자, 본문 40자 | 주 1회 갱신 |

### 금지어 제시 방식 (③ 핵심 기믹)

- 보스 데이터에 `banned_words` 필드 추가(→ §7 변경 제안 1). 보스의 핵심 약점 태그 단어 + 동의어 4~6개.
  - 예) B01 「답글 없는 사장」: `[환불, 응대, 답변, 고객센터, 사장]`
- UI: 입력창 상단에 금지어를 "사장님이 필터링 중인 단어"로 항상 노출. 입력 중 금지어 포함 시 **실시간 빨간 하이라이트 + 제출 버튼 비활성**(클라이언트 검사, LLM 호출 전 차단). 부분 문자열·초성 우회는 서버 정규화 검사로 2차 차단.
- 디자인 의도: 정공법 단어를 못 쓰게 해서 **우회 표현의 재치**가 창의성 점수의 주 득점원이 되게 한다. 사장님 답글 기믹(3턴마다 디버프 반박)과 세계관적으로 연결.

### 사기극 기믹 보강

- 의뢰 아이템의 **실제 결함 키워드 3개**를 "절대 언급 금지" 조건으로 제시(예: 녹슨 검 → `[녹, 이빠짐, 곰팡내]`). 언급 시 즉시 사기 실패(LLM 호출 없음, 클라 검사).
- 작성된 찬양 리뷰는 다른 유저의 상점에 해당 아이템과 함께 노출. 낚여서 구매한 유저 수 × 골드가 작성자에게 배당.

### 공통 UI 규칙

- 모든 작성권은 **서버가 발급하는 서명 토큰**(트리거 이벤트 검증 포함, TTL 10분). 클라이언트 임의 등록 불가.
- 이모지 허용(2개까지), 개행 금지, 전각 특수문자 금지.
- 제출 전 로컬 필터(욕설 사전 + 개인정보 정규식) 통과 필수 — LLM 호출 자체를 절약.

## 2. LLM 판정 루브릭

### 2.1 창의성 점수 (0~100)

단일 Haiku 호출이 아래 4개 축을 각각 채점하고 서버가 합산한다(LLM에 합계를 시키지 않음 — 산수 오류 방지).

| 축 | 배점 | 기준 |
|---|---|---|
| 유머/재치 | 0~30 | 한국어 리뷰 문화 특유의 비꼬기·과장·드립. 기시감 있는 클리셰("돈이 아깝다" 단독)는 10 이하 |
| 구체성/팩트성 | 0~25 | 대상의 속성을 구체적으로 저격하는가. 아무 대상에나 붙는 범용 문장은 8 이하 |
| 세계관 부합 | 0~20 | 판타지 사물을 커머스 리뷰 어법으로 다루는가("이 리치, CS가 없습니다") |
| 표현 독창성 | 0~25 | 금지어 우회의 재치(③ 구간 가중), 신선한 비유. 기존 카드 40장 문구와의 유사도가 높으면 감점 |

- **등급 컷**: 0~39 = 등록만 됨(효과 최저치) / 40~69 노멀 / 70~89 레어 / 90~100 레전드(박제 후보).
- 15점 미만은 "무의미/도배"로 간주하고 자동 반려(§4).
- **결정성 보장**: 텍스트 정규화(공백·초성·유니코드 NFC) 후 SHA-256 해시를 키로 판정 결과를 영구 캐시. 동일 텍스트 재제출 = LLM 호출 0회, 동일 결과(재롤 어뷰즈 차단).

### 2.2 점수 → 카드 수치 변환 공식

**효과 배율** `m = 0.85 + 0.005 × score` (범위 0.85~1.35, 소수 둘째 자리 반올림)

| 구간 | 효과 결정 방식 | 공식 |
|---|---|---|
| ③ 금지어 팩폭 | LLM이 **고정 디버프 풀 12종**에서 효과 유형 1개 선택(예: `보스 공격력 -2`, `장비 내구도 -3`, `매턴 의지 -1 도트 2턴`, `첫 행동 1턴 지연` 등) | 위력 = `floor(풀 기본치 × m)` |
| ① 사기극 | 수치 카드 아님 | 판매 성공률 = `20% + 0.5% × score` (20~70%) |
| ② 유언 | 수치 없음(공감 전용) | 노출 우선순위 가중치 `w = score` (같은 방 후보 중 w 확률비 추첨) |
| ④ 전단지 | 수치 없음 | `score < 60` → 미노출(본인만 봄). 60 이상만 로테이션 진입 |

- 디버프 풀 기본치는 전투 밸런스 기준선(플레이어 턴당 화력 8~12) 이하로 설계. 최대 배율 1.35에서도 기존 카드 상한(S04 12뎀)을 넘지 않게 풀 기본치를 캡.
- 디버프 지속·중첩 규칙은 비동기 시스템(상위 5슬롯)의 소관 — 본 문서는 개별 위력만 정의(§8 미해결 쟁점).

### 2.3 태그/계열 자동 부여 로직

- 태그 사전 = combat-model의 12태그(마감/내구도/무게/출력/연비/이펙트/속도/구성품/응대/디자인/감성/개연성).
- LLM이 `{태그: confidence(0~1)}` 목록 반환. 서버 규칙:
  - `confidence ≥ 0.7` 인 태그 상위 2개까지 부여
  - `0.4 ≤ confidence < 0.7` → 최상위 1개만
  - 전부 `< 0.4` → 무태그(항상 "일반" 판정으로만 작동)
- **계열 = 최상위 태그의 소속 계열** (매핑 표 고정). LLM에게 계열을 따로 묻지 않는다(불일치 방지).

### 2.4 판정 프롬프트 초안

- 모델: `claude-haiku-4-5`, structured outputs(`output_config.format`, json_schema)로 스키마 강제.
- 시스템 프롬프트는 **~4,500토큰으로 구성**(루브릭 전문 + 태그 사전 + 디버프 풀 + 모더레이션 규정 + few-shot 6례). Haiku 4.5 캐시 최소치 4,096토큰을 넘겨 프롬프트 캐시 적용 대상이 되게 한다. 가변 정보(대상 아이템, 금지어, 유저 텍스트)는 user 턴에만 넣는다(캐시 프리픽스 불변).

```
[system - 캐시 대상, 고정]
너는 게임 "이세계 리뷰용사"의 리뷰 심사위원(신)이다. 유저가 작성한 리뷰 텍스트를
아래 루브릭으로 채점하고 태그를 분류하고 모더레이션한다. 판정만 하고 효과를 창작하지 않는다.

## 채점 루브릭
humor(0-30): ... / specificity(0-25): ... / lore_fit(0-20): ... / originality(0-25): ...
(각 축의 기준·감점 사유 전문 + 점수대별 예시)

## 태그 사전 (12종, 각 태그의 정의와 예문)
마감: 물건의 만듦새·마무리 품질 ... (이하 12종)

## 디버프 효과 풀 (팩폭 구간에서만 선택, 12종)
D01 보스 공격력 -2 / D02 장비 내구도 -3 / ... (효과 ID만 선택 가능)

## 모더레이션 규정
allow: 경미한 비속어(대상 비하 없는 "쓰레기네" 류) — 이 게임의 기본 톤이다
block: 심한 욕설, 성적 표현, 혐오·차별(지역/성별/장애/인종), 실존 인물 지칭, 개인정보
rewrite_suggest: 실존 브랜드·상호 → 판타지 패러디명 치환안 제시

## few-shot 예시 6개 (구간별 입력→출력 JSON)

[user - 가변]
구간: 금지어_팩폭
대상: 던전 지배인 「답글 없는 사장」 (약점태그: 응대, 개연성)
금지어: 환불, 응대, 답변, 고객센터, 사장
리뷰 텍스트: "★ 문의 넣은 지 3주째인데 낫만 잘 갈고 계시네요. 직원 월급으로 숫돌 사셨나 봐요."
```


## 3. 판정 파이프라인 (서버 흐름)

```
클라 제출 → [1] 작성권 토큰 검증 → [2] 로컬필터 재검증(서버) → [3] 정규화 해시 캐시 조회
  → (캐시 미스 시) [4] Haiku 1회 호출 (structured output) → [5] 서버 합산/공식 적용
  → [6] verdict=allow → 등록 + 결과 캐시 저장 / verdict=block → 반려 UX
```

- 호출은 등록 시 동기 1회(목표 p95 < 4초). 배치 API는 등록에 쓰지 않는다(지연 최대 24h).
- **배치 API(50% 할인)는 사후 일괄 재검수 전용**: 모더레이션 정책 변경 시 기존 등록물 전수 재심사, 주간 박제 후보 정밀 재채점.

## 4. 모더레이션 기준

| 항목 | 판정 | 처리 |
|---|---|---|
| 경미한 비속어(대상 비하 없음: "쓰레기", "거지같네") | 허용 | 통과 — 악플 게임의 기본 톤 |
| 심한 욕설·성적 표현 | 반려 | 사유 반환, 위반 카운트 +1 |
| 혐오·차별(지역/성별/장애/인종/종교) | 반려 | 위반 카운트 +2 |
| **실존 브랜드/상호** | 조건부 | LLM이 패러디 치환안 제시("맥도날드"→"믹도랄드") → 유저가 수락하면 치환 후 등록, 거부하면 반려. 치환은 재호출 없이 문자열 교체만 |
| **실존 인물**(연예인·정치인·일반인 실명) | 반려 | 치환 제안 없음(리스크 큼). 위반 카운트 +2 |
| 개인정보(전화번호·주소·계좌 정규식) | 클라+서버 선차단 | LLM 호출 전 차단, 카운트 없음 |
| 무의미 도배(창의성 합산 15 미만) | 자동 반려 | "심사위원이 하품을 했습니다" 연출 |

### 반려 시 UX

1. 반려 사유 1줄(세계관 톤: "신들의 심사 규정 제7조 위반") + **수정 예시 1개**(LLM 출력의 `rewrite_suggestion` 재활용).
2. 작성권 유지, 즉시 재작성 가능. **재제출 2회까지**(총 3회 시도) — 이후 작성권 소멸.
3. 위반 카운트 누적: 24시간 내 3점 → 24h 작성 금지, 7일 내 6점 → 7일 금지. 신고 2건 접수된 전단지는 심사 전 즉시 내림.

## 5. 정식 카드 박제 조건 + 명예 보상

### 박제 조건 (3중 게이트, 모두 충족)

| 게이트 | 기준 |
|---|---|
| G1 창의성 | 등록 시 score ≥ 90 (레전드 등급) |
| G2 유저 검증 | 등록 후 30일 내 노출 100회 이상 **그리고** 공감률(공감/노출) 동기간 상위 5% |
| G3 큐레이션 | 주간 수동 확인(1~2인 개발 전제, 주 1회 30분). **주 최대 3장** 승격 |

### 명예 보상

| 보상 | 내용 |
|---|---|
| 닉네임 각인 | 카드 하단에 "— ○○○ 님의 실제 리뷰" 영구 표기 |
| 명성 | +500 (즉시) |
| 칭호 | "만물의 평론가" (박제 1장), "신들이 받아적는 자" (3장) |
| 로열티 | 박제 카드가 타 유저 런에서 사용될 때마다 명성 +1 (주 50 상한) |
| 갤러리 | 마을 "명예의 리뷰 전당"에 원문+작성일 전시 |

- 재화(골드) 보상은 **주지 않는다** — 박제는 순수 명예 트랙. 골드 경로가 되면 대필·매크로 유인이 생긴다.
- 박제 시 수치 재조정: 큐레이션 단계에서 운영자가 배율 m을 수동 확정(LLM 점수는 후보 선별용, 최종 밸런스는 사람).

## 6. 비용 추정 (Claude Haiku 4.5 기준)

단가: 입력 $1.00/M tok, 출력 $5.00/M tok. 캐시 읽기 0.1×, 캐시 쓰기 1.25×, 배치 50%.

### 호출당 비용

| 구성 | 토큰 | 캐시 히트 시 | 캐시 미스 시 |
|---|---|---|---|
| system(고정, 캐시) | 4,500 | $0.00045 (0.1×) | $0.005625 (1.25× 쓰기) |
| user(가변) | 500 | $0.0005 | $0.0005 |
| 출력(JSON) | 400 | $0.0020 | $0.0020 |
| **합계** | | **$0.0030 (≈ 4원)** | $0.0081 (≈ 11원) |

## 7. 변경 제안 (v0.1과의 조정 필요 사항 — 근거 포함)

1. **enemies 스키마에 `banned_words` 필드 추가** — 현재 B01의 `on_player_defeat`는 "보스 리뷰 남기기 발동"까지만 정의. 금지어 팩폭 구간이 이 작성 화면의 구체 스펙이 되며, 보스별 금지어는 적 데이터가 소유해야 한다(예: B01 `[환불, 응대, 답변, 고객센터, 사장]`). 사장님 답글 기믹과 동일한 화자(보스)가 필터를 건다는 설정으로 세계관 일관성도 확보.
2. **UGC 효과는 고정 효과 풀 select-only** — cards-v0.1은 `effect`를 자유 문자열로 기술하지만, UGC에서 이를 따르면 LLM이 효과를 "창작"하게 되어 파싱·밸런스·익스플로잇 문제가 생긴다. UGC는 효과 ID 선택 + 배율만 허용. 기존 카드 40장은 영향 없음(사람이 만든 데이터).
3. **'공감' 용어 통일** — X08 "공감 좀 눌러주세요"(게이지 +2)와 유언 리뷰의 공감 버튼이 같은 단어를 쓴다. 의도된 연결이면 X08 사용 시 "내 유언 리뷰 공감 수 1 소모" 같은 크로스 기믹 여지가 있고, 아니면 유언 쪽을 "추모"로 개명 권장. 세계관/전투 파트 판단 필요.
